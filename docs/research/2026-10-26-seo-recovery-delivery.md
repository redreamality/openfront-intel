## 工具需求验证

本轮在 Google 实际搜索 `openfront tracker`，结果中出现 OFstats，并实际打开 `https://ofstats.io/`。页面提供玩家及战队搜索、公开对局与排行榜等入口，并明确说明其非官方性质。已有工具覆盖主要任务，因此本站数据库增加带非官方标识的自然出口。没有进行 tracker 开发，也没有据一次搜索宣称它覆盖全部用户需求。

中文查询按国家/设备分开后样本很小，不能据总体均值或单次搜索位置推断缺少中文内容。保留现有中文主答案，继续用完整窗口观察。

## 事实与内容验收方法

正式版本通过 `gh api -X GET 'repos/openfrontio/OpenFrontIO/releases?per_page=10'` 核验：v0.35.4，发布时间 2026-10-24T20:08:23Z。站点配置、五语首页及 changelog 的版本合同通过 release audit。

已有文章维护新增显式 `--maintenance` 审计模式：五语文件必须已存在于 HEAD，官方来源和不少于 600 词研究记录仍必需。按现有 content-strategy 的维护规则，免除新增独立主题的 Reddit/YouTube 数量及八节配额，保留总字数、表格、内链与元数据要求，并检查每个 H2 和 H3 至少 401 words（中文按汉字）。工厂数量页删除围绕错误“两座工厂”结论展开的段落，合并为三节有事实依据的决策说明。三项独立策略测试保护新文原有配额及维护门槛，避免伪造社区来源或凑章节。

基线构建使用最新 main `7bc97e8` 的隔离快照；最终生产构建与该快照比较 HTML 内容及 SEO 完整诊断集合。Playwright 的 CMP/反馈测试环境与普通生产环境分开，不把测试注入造成的所有 HTML 变化列成业务变更。纯内容与入口维护按 runbook 使用 `pnpm exec astro build` 保留已验证的数据快照；临时 Playwright 配置只调整隔离端口与该构建命令，仍执行全部测试。

视觉复核后，First Match 与工厂用途的直接答案改由 DocLayout 在版本核验面板前输出，避免玩家先读研究说明；五语测试断言单个实例及正确顺序。工厂数量页德语和荷兰语原有搜索标题截断一并通过五语专用短标题修复。

## 失败与恢复

- 发布前远端同期维护 First Match，rebase 冲突逐处解决：保留远端 80% 严格阈值表和全部新增解释，22 个短 H3 转为保留原 ID 的段落，与本轮 605 个旧锚点共同保留；五语维护与核心审计再次通过。一次在 rebase 未完成时尝试推送 HEAD 被 Git 拒绝，核验远端未写入，完成 rebase 后重新验证再推送。
- Rebase 后完整回归首次 514/516：远端新增的四列 80% 阈值表在德语、荷兰语 390px 视口撑宽页面。五语该表统一增加可键盘聚焦、带本地化名称的局部横向滚动区域，保留表内全部事实及整页无溢出断言，再重跑完整套件。

- Windows 临时 ESM 脚本使用裸 `C:/` import 失败；改用 `file:///` URL 恢复。
- 上游 `git show` 曾在站点目录执行导致 invalid object；改为已核验上游 checkout 的工作目录恢复。
- First Match 新增英文段落超过核心审计的 240 字符上限；按自然句界拆成独立段落后通过。
- 浏览器旧 tab 已失效，重新创建 tab 读取真实页面；web 搜索工具空返回时改用可访问的浏览器搜索和正文，不把空结果当无需求。
- 工厂翻译补丁把同一路径同时 Delete/Add 被工具原子拒绝；文件未改变，改用 Update 分批替换恢复。runbook 标题上下文匹配失败同样未写入，读取真实标题后修正。
- 可视化辅助检查曾猜测 CookieConsent 与 cookie-consent 测试路径而报不存在；枚举真实组件后改读 ConsentBanner。实际隐私交互始终由完整套件覆盖。复杂引号的临时计数命令改为保存的 `.mjs` 脚本后成功。
- 首轮完整浏览器回归 515/516；德语 First Match 的 Overtime 表格最小宽度 424.25px，在 390px 视口下推宽整页。为该表添加可键盘聚焦、带名称的局部横向滚动区域，保留原有整页无溢出断言，再从头执行全套。
