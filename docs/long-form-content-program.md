# OpenFront Intel 长文内容生产计划与交付记录

更新日期：2026-09-02。规划窗口：未来 8–12 周。

本计划把每日任务从 freshness 审计转为持续内容生产。正式 Release 与已确认事实错误仍可打断排期，但无新版本不再等于无事可做。选题原则见 [`content-strategy.md`](content-strategy.md)，实时状态见 [`content-loop.md`](content-loop.md)。

本轮 A–E 五个批次、13 个主题已于 2026-08-22 全部完成：五语主答案、来源包、场景、自然入口与适用验证均已交付。它们继续作为路由边界和完成定义的基线；持续生产转入 `LF-COMMUNITY-ROLLING`，每次 schedule 循环从真实社区问题中批准并完整交付一个新 guide 主题。

## 玩家结果

玩家不只看到机制定义，而是能在具体局势中回答：现在该建什么、该攻击谁、哪条路线值得投资、怎样防住核打击，以及地图形状如何改变计划。

长文不以凑字数交付，但定时任务的新 guide 必须达到 1000 个英文正文词的最低门槛。每篇还必须提供独立搜索意图、当前版本边界、一手来源、决策框架、至少两个可核验场景、失败与反制，以及清晰的下一步阅读路径。

## 每日生产循环

1. 用不超过当日生产预算 10% 的时间完成正式 Release、事实错误和已跟踪状态门禁。
2. 依次搜索并实际打开 Reddit 与 YouTube 的相关内容；至少分析 3 个 Reddit 讨论和 3 个 YouTube 视频或可核验字幕。来源包逐项记录 URL、标题、发布日期或相对时效、玩家问题、可用观察、局限和访问日期；搜索摘要与标题列表不计数。
3. 把跨来源反复出现的问题合并为候选，选择一个具有唯一意图、成熟事实证据和自然入口的主题。Reddit/YouTube 用于需求和实战语境，玩法事实必须回到正式 Release、tag 源码、生成数据或官方测试核验；按需补充 GSC、GitHub、Feedlog、Discord、Steam、Twitch 等来源。
4. 在同一轮依次完成来源包、英文事实母稿、决策框架、两个以上场景、失败与反制、原创表格/解释图/工具、五语本地化、入口互链和验证。不得跨日拆阶段，也不得用正式 Release 响应替代 guide。
5. 当前主题来源不足或与现有主答案重复时，立即切换本轮下一个成熟候选；除工作区、权限、网络或基础设施硬阻塞外，不得以 `NO_CHANGE` 结束。
6. 结束前输出“长文验收”和“影响页面”。影响页面使用 `URL | 变更类型 | 原因` 表格，每个页面独占一行完整 `https://openfront.fyi/` 绝对 URL，标题写出去重 URL 总数；禁止用语言标签、“对应路由”“同上”、相对路径或分组省略代替。即使失败也要写明“无”及阻塞阶段。

## 单篇完成定义

- 新建唯一 `/guides/<slug>/` 主路由；只有用户明确要求或现有主答案完全承接同一意图时才允许做 1000+ 词的实质重写，并在报告解释为什么没有新路由。
- 英文 MDX 的可见正文至少 1000 词，不计 frontmatter、代码块和 URL；使用 `pnpm guide:audit -- --slug <slug> --source-pack <path>` 验证。fr/de/nl 各至少 750 词，zh 至少 1500 个汉字，且五语结构与结论等价。
- 40–80 words 的直接答案，明确适用版本与最后核验日期。
- 一手来源至少覆盖正式 Release、tag 源码、生成数据或官方测试中的适用组合。
- 来源包至少包含 3 个有效 Reddit URL、3 个有效 YouTube URL 和 1 个官方 OpenFront 一手来源；每个社区来源必须有实际分析笔记，不能只收集链接。
- 有一个可复述的决策框架，不只是机制百科。
- 至少两个带数字或明确地图状态的场景，并标注假设。
- 同时解释失败模式、对手反制和模式/地图调整。
- 有原创数据表、HTML/CSS 解释图、真实地图资产或可验证工具之一。
- en/zh/fr/de/nl 的数字、版本、键位和结论一致；译文保持自然，不逐词硬译。
- 新页面有唯一主入口、相邻页互链、canonical/hreflang、构建和链接验证。
- 只有新增或改变交互时增加 e2e；纯内容按严格审计、类型、构建和链接验证。
- 最终报告必须列出本轮新增或更新的全部公开页面，包括五语主路由、栏目入口和相邻互链页；文件路径、研究文档和测试文件不冒充公开页面。

## 暂不生产

- 不另建第二篇通用 beginner/how-to-play 页面；现有 `first-match` 是唯一支柱页。
- 不把通用 economy guide 再复制一份；新页只承接人口或建筑选择等独立意图。
- `ATTACK-01` 在高比例同 tick 行为与真实需求成熟前继续 Parked。
- 不批量生成 117 个地图页、所有单位页或所有建筑页；实体页必须有真实需求和足够数据。
- 不把未发布 PR、Issue 或 `main` 变化写成当前可用能力。
