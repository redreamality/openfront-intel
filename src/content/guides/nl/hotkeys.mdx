> Alles hieronder is de **standaard**-indeling. Sinds v24 kan elke toets opnieuw worden toegewezen in **Settings → Keybindings**, en sommige kunnen volledig worden losgekoppeld. Lees op macOS `Ctrl` als `Cmd`.

## "Hoe vuurt mijn tegenstander zo snel kernbommen af?"

Bijna elke nieuwe speler stelt deze vraag uiteindelijk. Er is **geen externe tool of autoclicker nodig** — het zijn twee ingebouwde mechanieken.

1. **Bouw-cijfertoetsen wapenen direct een structuur.** Druk op `8` en je cursor houdt al een atoombom vast — geen Radial-menu, geen klikken door niveaus. Linkerklik op een doel om te lanceren.
2. **Bommen blijven gewapend na het afvuren.** Wanneer je een atoombom (`8`) of waterstofbom (`9`) plaatst, blijft de bouw-"geest" op je cursor staan — je blijft dus simpelweg linksklikken om bom na bom op verschillende doelen te laten vallen. Druk op `Esc` of rechterklik om te stoppen.

Het "Shift ingedrukt houden en klikken om te herhalen" uit andere games is hier dus niet de exacte binding — maar voor bommen is het equivalent nog simpeler: **één tik op `8`, dan klik, klik, klik.** Elk ander gebouw wist de geest na één plaatsing, dus tik je het cijfer telkens opnieuw.

## Bouw- / eenheidstoetsen

Druk op het cijfer, klik dan met links waar je het wilt. Dit omzeilt het Radial-menu volledig en is hoe snelle spelers in de late game gebouwen (en bommen) aaneenrijgen.

| Toets | Bouwt |
| --- | --- |
| `1` | Stad |
| `2` | Fabriek |
| `3` | Haven |
| `4` | Verdedigingspost |
| `5` | Raketsilo |
| `6` | SAM-lanceerinstallatie |
| `7` | Oorlogsschip |
| `8` | Atoombom — **blijft gewapend voor herhaald vuren** |
| `9` | Waterstofbom — **blijft gewapend voor herhaald vuren** |
| `0` | MIRV |

- `Enter` — de gewapende eenheid onder de cursor bouwen (in plaats van klikken).
- `Esc` — het bouwvoorbeeld annuleren.
- `U` — de lanceerboogrichting (omhoog / omlaag) van een gewapende atoom- of waterstofbom omkeren.

## Muis

Standaardschema. Je kunt de knoppen omwisselen in **Settings → "Left click opens menu"**.

| Actie | Resultaat |
| --- | --- |
| Linkerklik op vijandelijke / niemandsland-grens | Aanvallen, of over water automatisch een transport sturen |
| Linkerklik op je land met een gewapende bouw | Dat gebouw plaatsen |
| Rechterklik | Radial- / Build-menu openen |
| `Ctrl` + linkerklik | Build-menu op die plek openen |
| `Alt` + linkerklik | Emote-menu openen |
| `Shift` + slepen | Meerdere oorlogsschepen in een vak selecteren |
| Attack Ratio-schuif slepen | Aandeel troepen per aanval instellen |
| Muiswiel | Zoom |
| Middelklik slepen | Beeld verschuiven |

## Radial-menu (herzien in v24)

Rechterklik op je eigen land om het te openen. Het is nu meerlaags: de kerngebouwen op de ring, met SAM, Fabriek, schip en upgrade-opties op het tweede niveau.

```
       Build City
            |
    Port -- ⊕ -- Defense
            |
       Missile Silo
```

Het Radial-menu is handig terwijl je de iconen leert — maar zodra je weet wat je wilt, zijn **de cijfertoetsen hierboven veel sneller**.

## Actiecombo's

- **Bommensalvo**: `8` → klik elk doel om de beurt aan (de atoombom blijft gewapend). Wissel naar `9` voor waterstofbommen.
- **Kustverdediging**: `3` (Haven) → plaatsen, dan `4` (Verdedigingspost) → strak tegen de binnenkant van de Haven.
- **Snelle economie**: `1` (Stad) → klik op open terrein; de geest verdwijnt, tik dus opnieuw `1` voor de volgende.
- **Bondgenootschap**: zweef over de rivaal en druk op `K`, of klik op zijn avatar → Request Alliance.

## Gevechtsritme

Het muiswerk van vaardige spelers roteert tussen drie zones:

1. **Het midden van je eigen land** — bouwen en upgraden (nu vooral met cijfertoetsen).
2. **De grens** — aanvallen en transporten.
3. **De minimap / spelerslijst** — de expansiecurves van rivalen volgen.

Wat je speelstijl ook is, de kernregel is: <strong>verlaat het slagveldbeeld niet</strong> — OpenFront gaat snel, en 10 seconden weg kan genoeg zijn om een Stad van eigenaar te laten wisselen.
