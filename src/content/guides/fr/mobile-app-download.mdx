## Commencez sur le site officiel

**Ouvrez [openfront.io](https://openfront.io/) dans le navigateur de votre téléphone pour jouer. Aucun APK n’est nécessaire pour le jeu Web.**

Sur iPhone ou iPad, ouvrez le menu **Partager** de Safari, puis choisissez **Ajouter à l’écran d’accueil**. Lancez la nouvelle icône pour jouer sans barre d’adresse. C’est un raccourci vers le site, pas l’installation d’un autre jeu depuis l’App Store.

Sur Android, vous pouvez jouer directement dans l’onglet. Si le navigateur propose **Installer** ou **Ajouter à l’écran d’accueil**, cette option crée un accès pratique. Son nom et sa disponibilité dépendent du navigateur.

Sur ordinateur, le site officiel propose aussi [OpenFront sur Steam](https://store.steampowered.com/app/3560670/OpenFront/). Cette version concerne l’ordinateur, pas l’installation sur Android ou iPhone. Navigateur et Steam sont deux accès distincts ; vérifiez la configuration requise sur la fiche du magasin.

Essayez une partie d’entraînement avant de rejoindre un salon public chargé. Le [guide des commandes tactiles](/fr/guides/mobile-controls/) explique toucher, déplacement, zoom et menu d’actions. Le [tutoriel de première partie](/fr/guides/first-match/) vous accompagne pour le départ et l’expansion.

**Vous cherchez un APK ?** Le jeu officiel dans le navigateur fonctionne sans. Un nom similaire sur un site de téléchargement ne prouve aucun lien officiel : suivez les liens de plateforme depuis le jeu.
