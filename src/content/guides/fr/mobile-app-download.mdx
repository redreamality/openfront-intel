## Réponse directe

**L’accès mobile officiel actuel à OpenFront est [openfront.io](https://openfront.io/) dans un navigateur moderne ; la Release officielle v0.33.14 ne fournit aucun APK.**

Cette phrase possède une date et une portée vérifiables. Le [README OpenFrontIO tagué](https://github.com/openfrontio/OpenFrontIO/blob/v0.33.14/README.md) décrit OpenFront comme un jeu en ligne et présente les navigateurs web modernes comme client multiplateforme. La [Release v0.33.14](https://github.com/openfrontio/OpenFrontIO/releases/tag/v0.33.14), publiée le 4 septembre 2026, ne contient aucun fichier téléchargeable joint : ni paquet Android, ni application App Store, ni installateur mobile séparé.

Ouvrez donc le domaine officiel au lieu de chercher un APK miroir. Un fichier tiers peut reprendre le nom OpenFront sans être une version officielle, et cette page ne peut vérifier ni son code, ni sa signature, ni ses mises à jour, ni le traitement du compte. L’absence actuelle de fichier joint ne promet pas qu’aucune application native n’existera un jour ; elle décrit seulement la version formelle contrôlée à la date indiquée.

## Ce que fait « Ajouter à l’écran d’accueil »

Sur iOS, lorsque le navigateur ne prend pas en charge le plein écran, l’interface officielle conseille **Add to Home Screen**. Les [textes anglais tagués](https://github.com/openfrontio/OpenFrontIO/blob/v0.33.14/resources/lang/en.json#L882-L891) précisent que l’ouverture depuis l’écran d’accueil lance le jeu sans barre d’adresse.

Cette action crée une icône qui ouvre le site. Elle ne prouve pas l’existence d’une application App Store et ne remplace pas le client web par un autre moteur. Dans Safari, ouvrez le site officiel, utilisez le menu Partager, puis choisissez Ajouter à l’écran d’accueil. Android peut proposer « Installer » ou « Ajouter à l’écran d’accueil » selon le navigateur ; vérifiez toujours que la destination reste `openfront.io`.

Une fois le jeu ouvert, consultez le [guide des commandes mobiles](/fr/guides/mobile-controls/) pour le toucher, le déplacement, le zoom, le menu radial et les Warships. Le [guide de première partie](/fr/guides/first-match/) couvre le spawn et l’ouverture. Cette page ne répond qu’à la question application, téléchargement et APK.
