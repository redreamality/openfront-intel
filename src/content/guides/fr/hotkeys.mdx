> Tout ce qui suit est la disposition **par défaut**. Depuis la v24, chaque touche peut être réassignée dans **Settings → Keybindings**, et certaines peuvent être totalement désactivées. Sur macOS, lisez `Ctrl` comme `Cmd`.

## « Comment mon adversaire envoie-t-il ses bombes aussi vite ? »

Presque tout nouveau joueur finit par poser cette question. Il n'y a **aucun outil externe ni autoclicker** : ce sont deux mécaniques intégrées.

1. **Les touches numérotées arment une structure instantanément.** Appuyez sur `8` et votre curseur tient déjà une bombe atomique — pas de menu Radial, pas de clics dans les niveaux. Clic gauche sur une cible pour lancer.
2. **Les bombes restent armées après le tir.** Quand vous posez une bombe atomique (`8`) ou à hydrogène (`9`), le « fantôme » de construction reste sur votre curseur : il suffit d'enchaîner les clics gauches pour larguer bombe après bombe sur différentes cibles. Appuyez sur `Esc` ou faites un clic droit pour arrêter.

Le « maintenir Maj et cliquer pour répéter » d'autres jeux n'est donc pas le binding exact ici — mais pour les bombes l'équivalent est encore plus simple : **un appui sur `8`, puis clic, clic, clic.** Toute autre structure efface le fantôme après une pose, vous re-tapez donc le chiffre à chaque fois.

## Touches de construction / unités

Appuyez sur le chiffre, puis clic gauche à l'endroit voulu. Cela contourne entièrement le menu Radial et c'est ainsi que les joueurs rapides enchaînent bâtiments (et bombes) en fin de partie.

| Touche | Construit |
| --- | --- |
| `1` | Ville |
| `2` | Usine |
| `3` | Port |
| `4` | Poste de défense |
| `5` | Silo à missiles |
| `6` | Lanceur SAM |
| `7` | Navire de guerre |
| `8` | Bombe atomique — **reste armée pour tir répété** |
| `9` | Bombe à hydrogène — **reste armée pour tir répété** |
| `0` | MIRV |

- `Enter` — construire l'unité armée sous le curseur (au lieu de cliquer).
- `Esc` — annuler l'aperçu de construction.
- `U` — inverser la direction de l'arc de lancement (haut / bas) d'une bombe atomique ou à hydrogène armée.

## Souris

Schéma par défaut. Vous pouvez inverser les boutons dans **Settings → « Left click opens menu »**.

| Action | Résultat |
| --- | --- |
| Clic gauche sur frontière ennemie / neutre | Attaquer, ou envoyer automatiquement un transport par la mer |
| Clic gauche sur votre terre avec une construction armée | Poser ce bâtiment |
| Clic droit | Ouvrir le menu Radial / Build |
| `Ctrl` + clic gauche | Ouvrir le menu Build à cet endroit |
| `Alt` + clic gauche | Ouvrir le menu d'émoticônes |
| `Maj` + glisser | Sélection en boîte de plusieurs navires |
| Glisser le curseur Attack Ratio | Régler la part de troupes envoyées par attaque |
| Molette | Zoom |
| Glisser-clic milieu | Déplacer la vue |

## Menu Radial (refondu en v24)

Clic droit sur votre propre terre pour l'ouvrir. Il est désormais multi-niveaux : les bâtiments principaux sur l'anneau, avec SAM, Usine, navire et options d'amélioration au second niveau.

```
       Build City
            |
    Port -- ⊕ -- Defense
            |
       Missile Silo
```

Le menu Radial est pratique le temps d'apprendre les icônes — mais une fois que vous savez ce que vous voulez, **les touches numérotées ci-dessus sont bien plus rapides**.

## Combos d'action

- **Salve de bombes** : `8` → cliquer chaque cible tour à tour (la bombe atomique reste armée). Passez à `9` pour les bombes à hydrogène.
- **Défense côtière** : `3` (Port) → poser, puis `4` (Poste de défense) → le coller contre l'intérieur du Port.
- **Économie express** : `1` (Ville) → cliquer sur du terrain libre ; le fantôme s'efface, re-tapez `1` pour la suivante.
- **Alliance** : survolez le rival et appuyez sur `K`, ou cliquez son avatar → Request Alliance.

## Rythme de combat

Le travail de souris des bons joueurs tourne entre trois zones :

1. **Le centre de votre terre** — construire et améliorer (surtout les touches numérotées désormais).
2. **La frontière** — attaques et transports.
3. **La minimap / liste des joueurs** — surveiller les courbes d'expansion des rivaux.

Quel que soit votre style, la règle d'or est de <strong>ne pas quitter la vue du champ de bataille</strong> — OpenFront va vite, et 10 secondes d'absence peuvent suffire pour qu'une Ville change de mains.
