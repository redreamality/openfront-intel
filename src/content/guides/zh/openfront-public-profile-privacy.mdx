v34 里你的对局可以被任何知道你账号的人阅读，所以问题不再是“我该怎么复盘自己的对局”，而是“我是否愿意让自己的整段战绩都变得可以被复盘”。这个决策是三种之一：让整段战绩保持可见、只在想让某个具体决策被复盘时分享单个可复制的对局链接、或者删除账号来隐藏一切。公开战绩既是学习工具，也是一个账号层面的选择。你控制这三种里哪一种适合你使用游戏的方式，代价与收益之间是一个权衡：你到底想要多有用、多具体的反馈，又愿意让别人把你多少对局拿在手里审视。

## v34 里“档案公开”到底意味着什么

v0.34.0 的功能版本，发布于 2026-09-14，在当前 v0.34.22 边界仍然有效，把默认状态从“你的战绩实际上是私密的”改成了“另一个玩家可以复盘绑定在一个账号上的对局”。这一行就驱动了本指南的全部内容。它的实际后果是：玩家可以打开绑定到你账号的对局并阅读它们，而版本说明把这同时框定为一个学习工具和一个账号选择。版本说明明确给出了两条对你的决策很重要的边界。第一，公开战绩不会暴露私有的 moderation 工具，所以复盘者看不到任何幕后的执法状态、不能从你的战绩里举报你、也不能对任何普通界面不会显示的东西采取行动。第二，公开战绩并不能证明某个玩家为什么做出某个操作；它展示的是操作序列和结果，并不展示意图，所以读者必须从可见序列去推断推理。

把版本边界钉清楚很重要，因为它决定了你能依赖什么。这个能力在 v0.34.0 引入，并原样贯穿 v0.34.18 到 v0.34.22 的补丁序列；其中没有任何一条补丁说明改动公开档案的暴露规则本身。v0.34.18 是上线了 Detailed View 大厅浏览器的补丁，带有单向的公开大厅列表、房主可选的一到五分钟开局窗口、以及十到一百的玩家上限，正因为如此，游戏的“大厅侧”才第一次变得可被观察，这也是 [列出大厅](/guides/list-lobbies/) 页面所记录的内容；v0.34.19 是加入了供第三方战绩站使用的账号链接 token 的补丁，那是一个独立的、需要你主动开通的暴露渠道，本指南稍后会专门讲。边界要点很简单：你今天正在决定的是从 v0.34.0 起就一直存在的暴露，所以这个决策是对着一条稳定规则做一次，而不是对着一个下次补丁可能会翻的东西做。如果你来自 v34 之前的版本，变化就是：你的战绩从安静变成了可被复盘，而本指南的三种选项正是你对此的回应方式。范围是整个账号，不是它的一部分：一旦这个能力开启，绑定到账号的每一场对局都落在可被复盘的表面上，并不存在一个逐场可见性开关让你把某场对局藏起来而其余保持公开，所以暴露是账号的属性，而不是任何单场对局的属性。

## 你的档案逼出的三个决策

因为档案在 v34 里默认是公开的，你实际上只有三种立场，它们与其说是一个光谱，不如说是三种代价各异的、彼此分明姿态。第一种是让整段战绩保持可见并任其被复盘，这是默认态，也是最适合“把对局当作训练记录”的玩家。第二种是保持档案公开但把它当作选择性工具：你不主动展示整段战绩，但当你想让某个具体判断被复盘时，你就分享历史卡片所暴露的那个可复制的对局链接，于是复盘者打开的正是那一场对局，而不是靠记忆或截图去猜。第三种是完全移除暴露，而版本说明为此指名的唯一机制是删除账号，因为账号没了就没有可绑定对局的东西，从而隐藏全部对局。

这三种之所以是仅有的三个选项，是因为 v34 没有给你“部分可见”的旋钮。你不能把某几场对局标为私密同时让其余公开，也不能发布档案却扣住那个可复制链接；这个能力在账号层面要么开要么关，而关的开关就是删除。这个缺位正是版本说明推着你去做的那个设计决策。如果你把对局当作一段你乐意任何人阅读的公开记录，就让战绩保持可见。如果你想要复盘的好处但不想承受常态暴露，可复制的对局链接就是版本说明指向的机制：“在请求建议时分享那一场具体对局”。如果常态暴露本身才是问题，唯一的手柄是删除，而这个手柄带着其他两个选项都没有的账号级代价。本指南的其余部分会把这三种逐一讲清楚——它们各自展示什么、代价是什么、适合哪种玩家——好让你选出与“你实际怎么用这个游戏”匹配的那个，而不是默认选那个最容易设置的。这三种姿态与 token 决策互不冲突，它是正交的：你可以持有三种姿态中的任意一种，同时仍然就“某个第三方战绩站是否可读你的战绩”做那个开/关判断，所以档案问题与 token 问题分开决定，而且可以同时指向不同方向。

## 读取一张公开的历史卡片：你和他人都能看到什么

当另一个玩家复盘你的对局时，复盘的单位是历史卡片所暴露的那个对局链接。版本说明指出历史卡片可以暴露一个可复制的对局链接，而这个链接正是“模糊地‘帮我看看我打得怎么样’”的请求与“复盘者真能回答的请求”之间的区别。复制链接并打开它，复盘者就落在正是那一场对局上，在那里他们能观看序列，并且因为 v34 里正常的 PlayerInfoPanel 在回放里是可用的，他们能在与实时对局相同的视图里看到玩家信息面板。实际效果是：复盘者不需要你口述局面；他们打开链接、拖到那个决策点，然后评论那个具体的操作而不是最终结果。这正是版本说明把可见性与“按顺序复盘决策，而不是只评判结果”这条指令配对的原因，也正是 [复盘回放](/guides/replay-review/) 页面在你复盘自己那一场时所用的同一套工具。

可见与不可见有具体的形状，而这个形状正是让链接成为一个公平的工具、而不是一个陷阱的原因。复盘者能看到的是建造序列、部队移动、进攻、比分和结果，这足以判断某个决策在当时的盘面下是否合理。复盘者不能看到的，是决策背后的推理，因为公开战绩并不能证明玩家为什么做出某个操作；他们也看不到私有的 moderation 状态，因为那不是公开表面的一部分。当你自己是请求复盘的那一方时，这种组合很关键：你交出的是一个决策的证据，却没有交出你的意图，所以一次好的复盘必须仅从序列得出。这对复盘者是一个公平的要求，但也是对你的一个约束，因为如果你要在分享链接之后为某个操作辩护，你就得辩护那个可见的序列，而不是背后那个私有的想法。链接是双向工具：它给复盘者一个清晰的目标，也把你钉在你实际做出的操作上，而这正是为了拿到具体、有用的反馈（而非泛泛的鼓励）所应得的那笔交易。对你最实用的结论是：在分享链接之前，唯一诚实的自问是“复盘者能否仅凭序列就得出他需要的结论”，因为链接交出了所有可见的东西、却交不出任何不可见的东西，而这两组之间的缺口，正是复盘变得有用或者跑偏的地方。

## 什么时候分享那一个具体对局链接是正确做法

第二种姿态，即分享单个可复制的对局链接，是 v34 里公开战绩最常见用法——把某个具体判断修正过来——的正确默认态。如果你的问题是“我那次入侵处理得对不对”，诚实的答案只在那一场具体的对局里，所以分享历史卡片上的可复制链接就是全部动作。拿着链接的复盘者能打开正是那一场对局，在部队投入的那一刻暂停，告诉你比例是否守住、时机是否对、替代方案是什么，这是截图或一段描述做不到的。这正是版本说明用“在请求建议时分享那一场具体对局”明确指名的姿态，也是单位暴露下反馈最有用的姿态，因为你只暴露一场对局而不是整段战绩。

有两种情况，单个链接姿态显然比让一切都可见更好。第一种是你在问一场具体的、较近的对局里做出的某个决策，并且想让复盘者看实际序列；单个链接就是能回答这个问题的最小暴露。第二种是你刚接触这个游戏、想让复盘者陪你走一遍一场对局，因为早期对局的一整段战绩大多是噪声，而一场有代表性的对局就是全部功课。两种情况里，单个链接都完成了任务并让你的其他对局保持私密，这正是适合“看重复盘好处、但不舒服于常态、永远在线记录”这种玩家的姿态。这里要避开的失败模式是相反的那个：把单个链接当作一种回避复盘的手段，通过分享一个并不包含你所问决策的链接来实现。如果链接指向的对局与问题所问的不是同一场，复盘者看的就是错误序列，反馈也就没用，所以纪律是在发出链接之前就把链接对齐到你想要复盘的那个精确决策。这种姿态也随你连续分享多少场而伸缩：一个链接回答一个问题，如果你发现自己一次发好几个链接，那你其实是在请求一次完整复盘，到那个时候单个链接姿态的代价就悄悄变成了完整战绩姿态的代价，所以那种情况下诚实的选择是让整段战绩保持可见，而不是一场一场喂链接直到战绩反正全暴露了。

## 公开战绩的隐私代价，具体化

第三种姿态是玩家最容易低估的，因为公开战绩的代价不是单一事件而是一种常态：任何能读你账号的人都能读你的对局。版本说明谨慎地划定了这种暴露能做什么，而这些边界值得说清楚，因为它们定义了你实际签下的最坏情况。公开战绩不会暴露私有 moderation 工具，所以战绩的读者看不到执法状态、也不能从你的记录触发任何普通界面本就不允许的东西。公开战绩并不证明你为什么做出某个操作，所以一个敌意或爱归罪的读者不能从你的记录里确立意图，只能从可见序列去断言。这两个边界意味着暴露被限制在你的“打法”上，而不是你与系统之间的关系上，这正是你在决定删除是否必要之前要记住的重点。

即使在那个边界之内，也有一种你应当计入的真实不对称。复盘你战绩的那个玩家，看的是一段你生产的记录，而复盘者可以按他喜欢的方式评判这个序列，因为版本说明自己的指令就是“按顺序复盘决策，而不是只评判结果”，这意味默认的人类反应是按结果来判断、并把导致失利的那个序列称作错误。不对称在于：你可以花一整场对局去学习，而复盘者可以花一分钟就断定你错了，而记录并不承载你的学习。如果你是那种读一条刻薄复盘会去改进的玩家，常态暴露就是净收益，因为代价是偶尔的苛刻评判，收益是一股持续不断的、任何人都能审计的对局供应。如果你是那种读一条刻薄复盘会往心里去的玩家，常态暴露就是净损失，因为那段本可以成为训练工具的记录变成了一个摩擦源，而单个链接姿态或删除，就是用更便宜的代价拿到你所需、同时避开那个代价的方式。这个决策关乎你对反馈的反应，而不是关乎这个功能本身，这正是版本说明把它框定为账号选择而非设置的原因。把代价装进头里的一个有用方法是把一次性代价与常态代价分开：选择可见档案的一次性代价基本上为零，因为默认本来就是开的；而常态代价是那种小而反复的可能性——你得意的一场对局被一个没有亲历那个决策的人给读出刻薄——而这股常态代价才是唯一能把天平从“保持可见”推向“关掉记录”的东西，所以你要把它当作一笔反复的小账来掂量，而不是一笔一次性的大账。

## 删除账号：唯一的隐藏开关，以及它真正的代价

v34 版本说明为隐藏你全部对局指名的唯一机制是删除账号，而它按版本说明的方式起作用，是因为账号没了就没有可绑定对局的东西。删除账号不会隐藏个别对局、也不会清空一个选择；它移除的是账号，连同让战绩可被复盘的那整个公开表面。这使删除成为三种姿态里最强的那一个、也是代价最高的那一个，因为它是唯一在账号层面不可逆的、也是唯一会移除你可能还想要的东西的那一个。v34 版本说明明确点出了它所属的风险类别：账号动作与对局内决策属于不同的类别，所以删除的决定是建立在账号本身的状况之上，而不是建立在任何单场对局的结果之上，应当把它当作一次永久的账号级改变来掂量，而不是当作对一场打砸了的对局的反应。

删除的代价是账号本身，而真正的权衡就在这一层。当你删除时，你交出的是进度、外观、与部落的关系、以及绑定在账号上的任何购买，换的是战绩不再可被复盘。其他两种姿态都没有让你交出其中任何一项，这正是删除是最后手段而非默认态的全部原因。实用检验是：常态暴露是否坏到值得为此交出账号？如果问题只是几条刻薄复盘，删除就是错误的工具，因为它为了一个单个链接姿态本就能解决的反馈问题而毁掉账号；如果问题是你不想让任何自己的打法被读到，那么删除就是那个工具，而你接受自己是在关掉账号、而不只是关掉档案。要从版本说明里抓住的一点是：删除的决定是你自己做一次、对着一条稳定规则做的，而备选永远是那两个更便宜的姿态，这正是你为什么应该把删除当作那个选项——只有在你先判定“让战绩保持可见”和“分享单个链接”两者都不可接受之后，才伸手去取。还有一个值得说清、好把代价计全的边界：删除同时也关掉了那两个更便宜的姿态的门，因为账号一旦没了，就没有账号可供保持可见、也没有账号可用来分享单个链接，所以这个决定不只是一句“隐藏战绩”，而是一句“交出账号”，即便两者指向同一个动作，它们也是两句不同的话。

## v0.34.19 的 token 决策：第二个、可选的暴露渠道

v34 增加了第二个大多数玩家会漏掉的暴露渠道，因为它与内置的公开档案是分开的，而它值得点出来，因为它是你真正能开能关的那一个决定。v0.34.19 补丁引入了供第三方战绩站使用的账号链接 token，那是你授权后允许某个外部网站读取你战绩的凭证。它与内置公开档案是不同的机制：内置档案把你的对局暴露给游戏内的任何玩家，而 token 把你的战绩暴露给一个你授予访问权的、特定的外部网站。这里的决策是关于你（如果有的话）信任哪一个第三方网站持有对你战绩的读取权，而由于它是你创建、并可吊销的 token，它是 v34 暴露故事里唯一真正“开/关”的选择，而不是一个你要么默认忍受、要么靠删除才能逃离的默认态。

token 决策叠在三种姿态框架之上，并不取代它。即使你让内置档案保持完全可见，你仍然可以拒绝把一个读取 token 交给某个战绩站；即使你正倾向于隐藏，token 也是你唯一能在不删账号的情况下关掉的那个渠道，这在担忧来自某个特定第三方聚合站、而非游戏内玩家时很有用。授权一个 token 的风险，是它授予的读取权：网站拿到 token 所暴露的东西，而如果你后来决定不信任那个网站，你就吊销 token，那就是隐藏决定里便宜、可逆的那一版。不授权的代价是你失去了第三方战绩聚合，这对大多数玩家是便利而非必需。正确姿态是把 token 当作默认关的渠道：在你还没有理由之前，不要授予战绩站读取权；一旦理由不再成立，就吊销它，因为 token 是 v34 暴露故事里那个两个方向移动都很便宜的手柄，也是唯一不碰账号本身的手柄。默认关之所以是正确判断、而不是谨慎判断，原因是在 benefit 很窄而 cost 很宽：token 买到的是一项便利——一个聚合你数字的战绩站——而一个已授权 token 的代价是第三方持有对你记录的读取权、只要 token 还活着，而一项之后还能重新授予的便利，不值得一个必须主动吊销的常设授权，所以你只在便利当下值得时授予 token、在它不再值得时吊销它。

## 一套决策程序与逐模式调整

把三种姿态与 token 决策合在一起，就得到一套你一分钟之内能跑完的程序，而模式和地图是改变答案的两个输入。程序是这样：如果你把对局当作训练记录、并且乐意任何人审计你的打法，就让内置战绩保持可见、默认不授予任何第三方 token、只在想让某个具体决策被复盘时分享单个可复制对局链接，并把链接对齐到你所问的那个精确决策。如果你想要复盘好处但不想要常态暴露，就保持档案公开但把单个链接姿态当作默认态，让你一次只暴露一场而非整段记录。如果常态暴露本身才是问题、你不想让任何自己的打法被读到，唯一的手柄是删除账号，而只有在你判定那两个更便宜的姿态都不可接受之后才取它，并接受自己是在关掉账号、交出它的进度、外观、部落关系和购买。

| 姿态 | 保持可见的东西 | 你交出的东西 | 适合时机 |
| --- | --- | --- | --- |
| 让战绩保持可见 | 完整对局战绩、回放里的 PlayerInfoPanel | 对游戏内任何玩家的常态暴露 | 你用自己对局训练并欢迎审计 |
| 单个对局链接 | 一次只分享一个可复制对局链接 | 只交出你选择分享的那一场 | 你想修正某个具体判断而不留公开记录 |
| 删除账号 | 没有；没有账号可绑定对局 | 进度、外观、部落关系、购买 | 你不想让任何自己的打法被读到 |

模式和地图把答案往一个方向调整。在竞技或部落环境里，你的战绩是你地位的一部分，队友和对手都会复盘它，可见战绩姿态是默认态，因为暴露正是重点，而单个链接或删除姿态会让你失去协作。在休闲环境里，你为游戏本身而非记录而玩，单个链接姿态是更安全的默认态，因为你拿到了所请求的复盘、却没有一段陌生人可以评判的常态记录。在比分与建造序列就是全部故事的那些地图上，暴露最有用了，因为复盘者能直接读出那个决策；在打法大量落在那些不会干净显示在序列里的选择上的地图上，暴露最没用，因为记录无法证明推理，而单个链接姿态是更好的匹配。这个决策对每个账号做一次、对着一条稳定的 v34 规则做，而模式和地图是唯一会移动它的输入，所以你可以一分钟定下它、不必每场对局都重新审视。
