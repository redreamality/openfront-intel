**直接答案：** 没有一个固定港口数量，而是一条三段式曲线。前期你的前两三个港口又便宜又接近满产，应该贪婪地抢；到第三、第四个收入单位时，价格停止翻倍、压平到固定的 1,000,000，商船总量上限也开始咬住你，边际港口的收益递减；到了后期，一个堆叠的四级或五级港口买的更多是战列舰维修速度，而不是更多有用的商船，那时就该停止增加港口容量、把钱花在收入或防御上。经验法则是：**前期建到三个港口，第四个看棋盘决定，把堆到五级的港口当作维修投资而不是商船投资。**

## "堆叠港口"到底做了什么

大多数搜"堆叠港口"的玩家，其实是在问：一个二级港口发出的商船是不是一个一级港口的两倍。诚实的答案是**差不多，但只在你舰队还小的时候。** 一个 N 级港口不是一个港口一口气做 N 倍的工作，而是像 N 个独立的生成机会，共享同一个全局商船池。开局时全场只有寥寥几条船，这些机会都落在几乎没满的上限上，二级港口确实能推出一级港口近两倍的流量——这正是社区说法里对的那部分：小规模堆叠接近线性，所以早期"把港口堆两格高"的直觉是成立的。

但机制的另一半是多数玩家忽略的。每个港口，无论堆不堆，都是从同一个共享全局池里抽商船，而这个池子被一条饱和曲线节流：场上船越多，每一次生成机会真正生出一艘船的概率就越低。所以一个五级港口并不保证发出五级流量——尤其当棋盘变满的时候。它保证的是五次机会，而当池子接近满时，其中大多数机会都会被压下去。实践上的翻译是：堆叠港口是一个**集中下注**。棋盘空时它效率高，棋盘满时效率低。分散的一群一级港口给你同样的机会数，但保留了地块的灵活性，当你想重新布置或防守时这很重要。堆叠赢在占地，还赢在一个次级加成——更高的港口等级修自己战列舰更快，这是一个真实但独立于商船数量的价值。所以当你问"两个港口堆叠是不是发出双倍商船"时，答案是**前期是，随着游戏变满逐渐趋近于否。**

## 共享成本曲线：为什么第三个港口是最后一个便宜的

关于港口数量，最重要的经济事实是**港口和工厂花的是同一条价格曲线。** 游戏不是给港口跑一条曲线、给工厂再跑一条；它只跑一条合并曲线，你的下一个收入单位的价格取决于你已经在两边一共买了多少港口等级和工厂。这条曲线每一步翻倍，然后撞到硬顶：合并收入预算的第一个单位是 125,000，第二个是 250,000，第三个是 500,000，**从第四个起每一个单位都是固定的 1,000,000**，因为曲线在那里封顶。这就是为什么第三个港口和第四个感觉不一样：到第三个之前你付的是翻倍曲线，从第四个起无论你再多买都付的是顶价。

堆叠的细节让决策更尖锐。一个五级港口不占曲线一个格——它算**五个单位**，所以一次性在曲线上跨五级翻倍，然后骑在顶价上。用具体钱来说，单个堆叠港口大约一级 125,000，二级累计约 375,000，三级约 875,000，四级约 187.5 万，五级约 287.5 万。最后那一步——花整整 100 万从四级升到五级——就是堆叠从便宜的效率玩法变成刻意奢侈的时刻。因为同一条曲线也给工厂定价，你每买一级港口就是一个你**没买**的工厂，每买一个工厂就是一个你没买的港口。这正是数量问题的核心：你不是孤立地决定"几个港口"，而是在两个收入引擎之间分配一个共享的、先翻倍后封顶的预算。第三个港口是价格还在曲线平缓段的最后一个；之后每个港口和每个工厂都花同样的顶价，所以两者之间的选择由棋盘决定，而不是由曲线决定。

## 饱和曲线：更多港口何时不再增加商船

"更多港口"有天然上限，是因为整场的商船总数不是无限的。游戏用一条饱和曲线节流全局舰队：船的数量爬向一个平台，而当舰队接近平台时，每一次生成机会真正产出一艘船的概率就下降。开局舰队小，曲线在陡峭段，几乎每个港口的每次机会都成功——这正是为什么前期用一波港口来奖励你这么慷慨。随着更多玩家建造、舰队变大，曲线滚过头，同样的机会开始更常失败，所以每个额外港口或工厂带回来的额外流量变小。

开发者对这条曲线的注释是理解上限有多硬的关键。平台不是一个几分钟就撞上的低数字；曲线的形状是**重港口投资在撞上全局硬顶之前几乎线性地增长收入**（文档里标注的硬顶在大约 800 艘船的区域）。这对玩家意味着：你在正常游戏里不会因为建了四五个港口就"没商船可用"——线性区足够长，合理的港口数量永远不会明显饿死。曲线**做的**是让**边际**港口没那么值钱：第五个港口带来的新流量比第二个少，不是游戏停止计算它，而是舰队已经接近平台、它的一部分机会被节流。所以收益递减是真的但渐进的。实践读法是：你前几个港口接近满效，中间几个港口好但有点打折扣，只有当你把舰队推得很大时，额外港口才真的停止增加**有用的**商船。这就是社区"港口堆到顶已经死了"论证的机械内核：在曲线的极端端它是真的，在正常中期它是假的，区别是舰队规模，不是你的港口数。

## 三段式：何时买第一个、第三个，何时停

把两个机制——先翻倍后封顶的价格曲线和舰队饱和曲线——转成一个简单的三段式规则。**第一段，便宜且饥渴段，是前期你和你对手的舰队都小的阶段。** 这里价格曲线还在平缓段，饱和曲线还在陡峭段，所以你买的每个港口既买得起又几乎满产。在这一段，"几个港口"的答案是**抢在对手之前**：你的前两三个港口是你整场能拿到的最高每金收入，犹豫是前期主要的失败。如果你有金、有地，正确的早期打法是**对港口稍微贪婪**，因为棋盘空到足够程度，让它们全都回本。

**第二段，边际段，大约从你的第三、第四个收入单位开始。** 价格曲线已经撞到 1,000,000 的顶，所以下一个港口和下一个工厂花一样的钱，而舰队在变大，饱和曲线开始啃每一口边际港口。这一段数量不再是"我买得起几个"，而是"这个港口能赢过什么"——当你有可靠的贸易伙伴、能保持航线畅通时港口赢过工厂，当棋盘敌对、你需要不依赖别人的收入时工厂赢过港口。第四个收入单位是棋盘驱动的决策，诚实的答案是大多数玩家应该停在**四个总收入单位**（港口加工厂合计），除非棋盘明显奖励更多。

**第三段，维修段，是后期舰队很大之后。** 饱和曲线已经平了，额外港口大多不再增加有用的商船，一个堆叠的四级或五级港口最好被理解成一个**战列舰维修投资**：更高的港口等级修自己的战列舰更快，在冻住的终局那维修价值常常比多一条被节流的商船更有用。所以第三段停止增加港口**容量**去换商船，转而决定剩下的预算是花在维修加成的港口堆、还是在保持独立收入的工厂、还是花在防御上。三段式给你一个跨地图稳定的决策过程：前期贪婪、中期看棋盘、后期把港口当作维修而不是商船数量。

## 场景 A：三人中期，何时买第三个港口

具体数字让三段式落地。想象一个三人大局，进行到前期大约四分之三：你有两个一级港口、一个工厂，收入稳定，两个对手各有一个港口、还在造军队。你在考虑是买**第三个港口**（你的第四个收入单位）还是第二个工厂。用曲线：你的下一个收入单位是共享曲线上的第四个，所以无论买哪个都花固定的 **1,000,000**——曲线不再区分两者，所以决策纯看棋盘。再用饱和读法：三人中期舰队中等，曲线已经过了最陡段但离平台还远，所以第三个港口仍有产出，但每金明显不如你前两个。棋盘测试：你有没有一个稳定贸易伙伴能持续供货？你能否保持那条航线畅通？如果是，第三个港口挣到开放贸易溢价，你买它。如果棋盘在争夺、对手正要对你禁运或劫航，那个 1,000,000 应该换成独立的工厂。

你下决定前应该先声明的假设：(1) 你至少有一个在商船航程内的可靠贸易伙伴，(2) 你的航线当前没被劫航，(3) 你有富余的金、不破你的军事底线。在这三条假设下，第三个港口是这个中期的更好买法，因为舰队还小到它接近满产，开放贸易溢价超过工厂的独立收入。一旦假设 (2) 破了——对手把战列舰压到你航线上——同样的 1,000,000 应该翻转为工厂，因为港口价值在贸易能被否定时崩塌。这就是整个数量问题的压缩版：第三个港口是**有条件的**买法，条件是"开放且可靠的贸易"。如果你能在棋盘上指出这个条件，买港口；不能，买工厂。两者同样贵，只有棋盘决定。

## 场景 B：终局赛跑，为什么港口堆到顶不再回本

现在把同一个问题放到终局，"港口堆到顶已经死了"的论证在此咬合。你在一个冻住的 1v1 或低贸易终局，舰队很大，双方都深入收入赛跑，你在纠结要不要把**堆叠港口推到五级**（比四级多花 1,000,000）去挤更多商船。用饱和读法：舰队已接近平台，那额外一级的生成机会被重度节流——你花顶价买一个接近零的商船增量。用成本读法：那个 1,000,000 和一个完整工厂或一次重大防御同价，所以你买的不是便宜效率增量，是奢侈。五级堆**仍然**买到的，是战列舰维修加成：更高的港口等级修战列舰更快，在双方都在流血战列舰的冻住终局，那个维修价值可能是决定性优势。所以终局读法是**你不该为了商船去堆港口**——曲线已经平了，边际商船几乎不值钱——但你**可能**仍然该买一个顶级端口专门为了维修，且仅当你有真的需要维修的战列舰舰队。

具体决策：如果你的终局胜线是"我的战列舰活着的同时收入超过他们"，五级端口作为维修是合理的，你应该以维修而不是商船数量来框定这次购买。如果你的胜线是"建一支收入超过他们的舰队"，那个保持独立收入的工厂是更好的 1,000,000，因为被节流的堆叠商船增量回不了本。如果你的胜线是防御、你能否定他们的航线，那两者都不该买，应该把钱花在防御上，因为整条收入赛跑只是决定比赛那件事的干扰项。社区那句"港口堆到顶已经死了"警告抓到的失败模式正好是：玩家因为早期线性段让它感觉一直回本而不停堆港口，然后发现边际商船被节流、他们真正想要的维修本可以更便宜地拿到。修正方法是明确你买的是哪个价值——维修还是独立收入——当棋盘上两个价值都不存在时拒绝这次购买。

## 失败模式与反制：禁运、劫航与上限

忽略否定模式的港口数量计划，纸面上看着对、实战里会失败，因为港口是别的玩家能**关掉**的收入源。三种真实失败模式是禁运、劫航和舰队上限，各有各的反制。**禁运**是最干净的否定：对手可以对你禁运，你的港口贸易收入停了，而你的港口数量原封不动。反制是港口重经济对愿意禁运的玩家很脆，所以健康计划要保留一些**不依赖任何贸易伙伴的工厂收入**——你越多收入走开放航线，单次禁运就越伤你。棋盘规则是：如果某个具体对手是会禁运的玩家，就压住你的港口占比、保留一个扛得住禁运的工厂底线。

**劫航**是同一思路的动力学版本：对手把战列舰放到你的航线上，你的船停止靠港，港口还在但不再回本。反制是航线保护——要么一道 SAM 屏蔽，要么你自己的战列舰在航线上——但保护花的钱和你想保护的那个港口一样，所以诚实的算法是港口收入是否超过保护成本。如果不超过，那个港口不值得留着开放，应该把那部分预算转成工厂。**舰队上限**是自找的失败：建了比舰队能用的还多的港口，多出的港口因为饱和曲线已经节流了池子而闲置。反制是舰队接近平台的那一刻停止增加港口容量，把省下的金花在维修或防御上。统一教训是**港口数量只和你保持贸易开放的能力一样好**；一个说"建 N 个港口"的计划不完整，除非还有一行"以及我怎么让这 N 个港口不被禁运、不被劫航、不闲置"。否定模式不是脚注——它们是数量必须在每个阶段都保持棋盘条件的原因。

## 模式与地图调整：FFA 对 1v1、大地图对小地图

三段式曲线稳定，但**阈值**随模式和地图大小移动，所以"几个港口"的答案必须调到你在打的那张桌子。**在 FFA（三人或更多）**，舰队更大，饱和曲线滚过头更早，因为每个对手都在往共享全局池里加。这意味着 FFA 的边际港口比 1v1 更早打折，所以 FFA 对"几个"的答案是**稍少一点港口、更高一点工厂底线**——你需要更多独立收入，因为能禁运或劫航你的人更多，开放贸易溢价更难守住，因为棋盘更被争夺。FFA 实践规则：前两三个港口照旧早拿，但边际段比 1v1 更倾向工厂，把开放贸易溢价当作你会失去的奖励、而不是你能依赖的底线。

**在 1v1 或 1v2**，舰队更小，曲线在陡峭段停留更久，所以港口多保持一点产出、开放贸易溢价在有伙伴时更可靠。1v1/1v2 的答案是**你可以跑更高的港口占比**，因为否定源更少、舰队更小；但这同时意味着一次禁运或单个对手战列舰压上你的航线，是你收入里更大的一块，所以你仍然需要工厂底线——只是比 FFA 小。**地图大小**调同一个轴：在**小地图**上舰队相对上限更密，曲线滚过头更快，港口更早停止增加有用商船，所以小地图答案是"更少、更早、更早转向堆叠港口的维修价值"。在**大地图**上舰队更分散，曲线保持平缓更久，后期线性区更长，所以大地图答案是"你可以多堆一会儿港口、边际港口才停止回本，而且开放航线因为更长、更少被争夺而更容易保持"。调整原则每种情况都一样：**舰队相对上限越密，港口越早停止加商船，你在维修和独立收入上放越多权重**；舰队越稀，你越能长时间为了商船堆港口。

| 2 — 边际 | 中等舰队，中期 | 1,000,000（顶） | 好但打折 | 和工厂比；只有开放可靠贸易时港口才赢 |
| 3 — 维修 | 大舰队，终局 | 1,000,000（顶） | 接近零 | 为维修买，不为商船；否则花在收入/防御 |

这样跑。任何港口购买前问：**我在哪一段？** 读棋盘上的舰队——小，你在第一段，答案是买；中等，你在第二段，答案是"只有我能保持可靠贸易航线，且同样金能买一个扛得住禁运的工厂"；大，你在第三段，答案是"只有我专门想要维修、且有真的需要维修的战列舰"。这张表也编码了否定检查：第二段里，港口行只在贸易航线开放且可靠时成立；一旦对手能禁运或劫航它，同样价格的工厂行赢。把这张表放在你的局内计划旁边，你就会停止把"几个港口"当一个数字来问，开始问真正决定它的三个问题：舰队有多空、我的贸易是否开放、我是在买商船还是买维修。这就是完整答案，它跨模式和地图稳定，即使精确价格变了也一样。

*版本边界：这里一切反映当前版本（v0.34.x），并与 2026-09-26 发布的 v0.34.20 release 一致——共享成本曲线、舰队饱和曲线、按等级生成商船的掷骰、按等级战列舰维修加成在那个 release 都存在且数值一致。若未来 release 改了成本曲线或饱和曲线，表里价格会变，但三段式决策逻辑不会变。*
