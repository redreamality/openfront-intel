## 直接答案：分五层读图

不要先问画面上哪个国家看起来最安全。按以下顺序读取任意 OpenFront 地图：

1. **可通行陆地**：到底有多少领土可以被占领？
2. **陆地连通块**：哪些区域能陆路连通，哪些必须运输？
3. **水域网络**：舰队共享一个战区，还是被分在互不相通的水体？
4. **不可通行地形**：哪些可见形状不能占领、攻击、核击，也不能让核弹轨迹穿过？
5. **出生与模式**：玩家、Nations、队伍、Compact 和 modifier 怎样填入这副骨架？

这个顺序把地图文件中的事实与某个房间产生的局面分开。它能避免把黑色背景当成空地、把 5 个 Nations 当成 5 个真人槽，或在没有确认可通行性时宣布某条细线是 chokepoint。

## 地图文件能证明什么

正式 v33.7 的地形每格使用 1 byte。land、shoreline、ocean 与 magnitude 位共同决定 tile 类型；land 且 magnitude 为 31 就是 impassable。

游戏按上、下、左、右四邻接检查，不会从地图边缘绕到另一侧。因此可以直接从 `map.bin` 复算陆地与水域连通块。

静态文件能证明尺寸、可通行陆地、impassable、连通块、临水关系、Nation 定义与固定坐标。它不能证明平均局长、最佳出生、胜率或某个 Port 的收益。

下面的数字是读图仪器，不是对局替代品。

## 第一层：先量可通行陆地

完整网格包含水域和不可通行背景。可通行陆地才是普通领土控制的对象，也是公开人数公式的输入。

这个区别会反转“最大”排名。Sol 有 11,204,096 个完整网格，却只有 877,713 个可通行陆地格；The Box 则有 4,194,304 个可通行陆地格。

开局时，陆地总量与陆地占比分别回答不同问题：

- **总量高、占比高**：陆路多，领土成长空间大。
- **总量高、占比低**：画布很大，但水域和分割可能主导战略。
- **总量低、占比高**：陆地压力集中，海上绕行较少。
- **占比低且连通块多**：运输与舰队位置成为核心。

不要自动把四类变成 tier list。狭长全陆走廊可能比多出口的低陆地占比地图更受限制。

## 第二层：找主要陆地连通块

陆地连通块是一组能通过四邻接连续到达的可通行陆地。如果两块区域属于不同 component，普通陆地扩张就无法直接连接，必须运输或依赖改变地形的规则。

先数连通块，再按陆地份额排序。原始数量常被小岛放大，因此优先查看少数几个占据大部分陆地的主块。

依次问三个问题：

1. 是否有一个连通块占据大多数陆地？
2. 是否有两到五个规模接近的主战区？
3. 还有多少陆地散落在卫星小岛？

单一主块更看重连续边界和纵深。多个主块意味着区域控制不等于全图控制。大量卫星小岛则提高中转 Port、运输与远岸情报的价值。

“连通”不等于“开阔”。一个 component 内仍可能只有一格细颈、山地或长走廊。连通块是第一层筛选，通道宽度和地形 cost 仍需放大检查。

## 第三层：把水域连通和海岸分开

水域连通块告诉你舰队是否理论上共享一片连续水体，还是必须在互不相通的系统中分别建造。

单一水域网络不代表每条路线都短。它只证明存在连续水路；长距离绕行、敌对海岸、寻路 cost 与制海权仍会决定路线能否使用。

从正式 v31 起，Ports、Trade Ships 与 Warships 可在所有水体运行，不再只限 ocean。孤立湖泊也能承载海军，但不会自动连接另一座湖。

临水格只能作为战术线索，不能当成 Port 数量。相邻水域的 tile 仍可能不适合建造，或在战略上过度暴露。

决定海军开局前，先确认：

- 出生海岸接入哪一个水域 component；
- 该水域能到达哪些主陆块；
- 第二个 Port 是扩展通路，还是重复同一海岸；
- 哪个对手能在贸易或运输回本前争夺航线。

确认战区后，再用[团队海军控制指南](/zh/strategies/team-naval-control/)安排舰队职责。

## 第四层：标出 impassable

在 v33.7 中，impassable 是 magnitude 31 的 land-bit 地形。它不能被占领、攻击或核击，核弹轨迹也不能穿过。

这比防御加成或高成本山地更强：它是地形图上的硬边界。

用 impassable 回答四个问题：

- 一个看似连续的区域是否被切成多个可玩 component？
- 某条通道是终止于硬墙，还是仅经过荒地？
- 核弹飞行线能否跨越该形状？
- 画面上的内部空间是否其实不会计入公开容量？

不要只凭颜色判断。图形设置与地图美术会改变外观，地形数据才是权威。

## 第五层：加入大厅人口与出生规则

读完骨架后，才把本局配置放进去。

公开 FFA 容量从完整图可通行陆地计算，并从三档中选择。Compact 把已选档位降到 25%；Team 会按队伍取整，Crowded 另有分支。

Nation 条目是 AI 配置，不是人类槽位。Random Spawn、固定团队区域、default Nations、自定义数量与 bots 可以让同一地形承受完全不同的压力。

某一局以大厅显示为最终事实。[地图尺寸与 Compact 指南](/zh/guides/map-size-compact-mode/)解释候选数字怎样产生。

## 案例一：Svalmel

正式 v28 把 Svalmel 定义为圣诞主题地图，并列出 5 个 Nations。当前 v33.7 manifest 仍保留 5 个带固定坐标的 Nation。

![OpenFront 官方 Svalmel 地图缩略图，展示四组主要岛群与外围水域](/images/maps/svalmel-v33.7.webp)

*未修改的 Svalmel 地图资产：OpenFront / OpenFront Inc. and Contributors，[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)；[OpenFrontIO v0.33.7 来源](https://github.com/openfrontio/OpenFrontIO/blob/v0.33.7/resources/maps/svalmel/thumbnail.webp)。*

### 已核验的 Normal 拓扑

| 指标 | 数值 |
| --- | ---: |
| 网格 | 1,700 x 1,580 |
| 可通行陆地 | 1,011,623，占网格 37.66% |
| impassable | 0 |
| 陆地连通块 | 26 |
| 至少 1,000 格的连通块 | 13 |
| 最大块份额 | 可通行陆地的 35.28% |
| 前四块合计 | 91.48% |
| 水域连通块 | 1 |

Svalmel 不是“几十个同等小岛”的均匀群岛。四个主陆块已占可通行陆地的 91.48%，前两块就占 66.21%。

所以它更像四个主战区加卫星岛。控制一座大岛很重要，却不会自动产生通往另外三座的陆地边界。

所有水格形成一个连通网络。运输与舰队理论上可以连接各战区，但路线长度和敌方制海权决定这条连接是否实际可用。

最大两块分别占 35.28% 和 30.93%，不足以证明“完全对称”。在写平衡结论前，仍需测试出生压力。

### Svalmel 开局问题

- 出生位于哪个主岛，岛上还剩多少扩张空间？
- 第一位对手与你同陆块，还是隔水？
- 哪段海岸能通向不止一个主战区？
- 延迟 Port 是否会让你被困在单岛？
- 哪座卫星岛是有效中转，而不是经济陷阱？

Compact Svalmel 使用 850 x 790 地形、248,032 个可通行陆地格和 24 个陆地连通块。主要结构仍在，次要小岛减少。

## 案例二：Dyslexdria

正式 v31 把 Dyslexdria 称为回归的愚人节地图，以重新着色的 World 为基础。当前 v33.7 资产包含后续 v33 更新，应以这一版为现行事实。

![OpenFront 官方 Dyslexdria 地图缩略图，展示超宽且高度分割的世界构图](/images/maps/dyslexdria-v33.7.webp)

*未修改的 Dyslexdria 地图资产：OpenFront / OpenFront Inc. and Contributors，[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)；[OpenFrontIO v0.33.7 来源](https://github.com/openfrontio/OpenFrontIO/blob/v0.33.7/resources/maps/dyslexdria/thumbnail.webp)。*

### 已核验的 Normal 拓扑

| 指标 | 数值 |
| --- | ---: |
| 网格 | 3,308 x 1,440 |
| 可通行陆地 | 2,103,254，占网格 44.15% |
| impassable land-bit 格 | 175,320 |
| 陆地连通块 | 224 |
| 至少 1,000 格的连通块 | 52 |
| 最大块份额 | 可通行陆地的 16.77% |
| 前十大块合计 | 85.78% |
| 水域连通块 | 1 |

Dyslexdria 没有一块主大陆统治全图。最大块只占 16.77%，需要前十个主要区域才达到 85.78%。

因此，区域胜利不等于全局控制。玩家可以在一个战区很强，却无法在不跨水的情况下立刻支援远处。

原始 224 个 component 含有明显的小岛噪声。正文应优先看前十大块，其余碎片更适合作为中转、逃生或牵制地形。

175,320 个 impassable 格不会计入可通行陆地容量。缩略图里的黑色或背景区域不能当成尚未占领的空地。

Dyslexdria 定义 82 个主 Nations：69 个有坐标，13 个无坐标；另有 189 个 additional 后备名称。Normal 公开 default 可使用全部 82 个，Compact default 为 20 个。这些都不是真人上限。

Compact Dyslexdria 使用 1,654 x 720 地形、508,102 个可通行陆地格、43,913 个 impassable 格和 142 个陆地连通块。多战区身份仍在，小碎片显著减少。

## 把读图转成开局

出生后使用一条短决策链。

### 1. 给自己的陆块命名

判断自己在主大陆、多个对等战区之一、半岛，还是卫星岛。这个结论决定仅靠陆地扩张能否进入全局中心。

### 2. 标出前两个真实出口

选一条主扩张路线和一条备用路线。被 impassable 堵住的“出口”不算备用。

### 3. 只数有意义的邻居

先忽略短期无法接触的远方名字。优先关注同陆块玩家，再关注能争夺同一海岸或狭窄通道的人。

### 4. 判断水域是通路还是暴露面

好海岸能打开多个战区；坏海岸只会消耗海军投资，同时让唯一重要的陆地对手进攻。

### 5. 设一条停止线

不要扩张到所有边界同样脆弱。停在地形收窄、Defense 可重叠，或 Port 能连接下一个战区的位置。

[第一局指南](/zh/guides/first-match/)会把这套流程扩展成完整出生与首次扩张方案。

## 识别常见拓扑家族

### 单一主大陆

连续边界和多个陆地邻居更重要。内陆成长与边界形状通常比早期运输更优先。

不要默认中心最好。中心位置往往用多方向通路换来更多前线。

### 多个主岛

把每座岛当成区域经济体，把每段海岸当成转场决策。先取得足够本地陆地，再为所有可能航线投资。

Svalmel 是已核验案例：四个主块占绝大部分陆地，外围共享一个水域网络。

### 长走廊或河道条带

前线方向受限，但距离可能很长。后方纵深重要，一条被封路线就可能隔断支援。

完整网格会掩盖形状。Passage 的 6,000 x 400 尺寸就是必须检查长宽比的信号。

### 碎片化世界

多个大 component 会产生相对独立的战争。情报与运输时机重要，因为本地优势无法瞬间支援远方。

Dyslexdria 是已核验案例：最大块不到可通行陆地的六分之一。

### 多个断开的水体

不同水域 component 中的 Ports 支持相互独立的舰队与贸易系统。一片水域的优势不会保护另一片。

必须核对真实连通性，不能假设两片蓝色会从地图边缘相接；v33.7 地图边缘不环绕。

## 常见误区

### 只按视觉面积选出生

看起来很大的区域可能包含 impassable，或被切成多个 component。落点前应先找真实出口。

### 把每条细线都叫 chokepoint

有效 chokepoint 必须可通行、宽度可守、确有流量，而且你能控制。缩略图上的细线本身无法证明这些条件。

### 看到水就建 Port

只有当水域能抵达有价值战区，且你能承担机会成本时，海岸才有价值。临水格不是贸易收益公式。

### 把 Nations 当玩家

Nation manifest 控制 AI 身份和部分固定出生坐标。真人槽位来自大厅配置。

### 在 Compact 照抄 Normal 计划

主要地理仍在，但小岛、人数档、bots、Nations 和距离都会变化。重新检查接敌顺序，不要把所有时间简单除以二。

### 没有对局证据就宣布最佳出生

静态拓扑可以解释选择与风险，不能提供胜率，也无法控制玩家水平、队伍和 modifier。

## FAQ

### 陌生地图第一眼先看什么？

先确认自己的可通行陆地 component 和两个真实出口，再看海岸接入哪个水域网络，并核对可见屏障是否 impassable。

### 一个水域 component 是否代表海军很容易？

不是。它只证明存在连续水路。距离、敌舰、Port 接入和寻路仍会决定路线是否有用。

### 陆地 component 越多，海军就越强吗？

它会增加运输需求，却不保证经济更好。小岛可能增加路线负担，却没有足够陆地回报基础设施。

### 拓扑能告诉我最佳出生吗？

它能排除错误假设并说明取舍。真正的出生排名需要在相同模式和人口下进行多局验证。

### Compact 怎样改变拓扑？

它加载宽高减半的地形，总网格为四分之一。主 component 通常保留，小岛和细海岸可能消失。

### 为什么要单独统计 impassable？

它的 land bit 会让原始计数看起来像陆地，却不能占领，也不计入可通行容量；同时还会阻挡攻击、核击与核弹轨迹。
