## 直接答案：最快的 OpenFront 操作

按数字键装填建筑或单位，再左键点击目标位置。数字键可以跳过 Radial 菜单，所以熟练玩家能比逐层点图标更快地下达建造命令。

要连续发射核弹，按一次 `8` 装填原子弹，或按一次 `9` 装填氢弹。核弹发射后仍保持装填，可以继续左键点击多个目标。

不需要连点器或外挂。计划中的最后一发结束后，按 `Esc` 或右键清空装填状态。普通建筑放置一次后通常会自动清空，下一座要重新按数字键。

本文列出按站内 v33 参考核验的默认键位。v24 起可在 **Settings → Keybindings** 重映射全部按键，部分操作也可以完全解绑。

macOS 用户可把 `Ctrl` 理解为 `Cmd`。若按键没有反应，先查看游戏内键位设置，再判断该操作是否已经改变。

## 记按键前要理解的概念

OpenFront 的点击行为取决于上下文。左键可能攻击边境、跨水派运输船，也可能放置已装填建筑，具体由光标位置和当前装填状态决定。

**已装填建造**是选择建筑或武器后跟随光标的预览。数字键会立刻进入该状态；`Esc` 取消，`Enter` 则在光标位置确认。

**Radial 菜单**是右键打开的可视化建造菜单。刚学图标或查看升级时很有用；已经确定要造什么时，数字键更快。

**攻击比例**决定一次攻击投入多少现有兵力。`T` 降低、`Y` 提高，修改的是屏幕滑块所代表的同一个数值。

镜头按键不会花费资源，也不会发起攻击。它们的作用是让鼠标留在前线附近，同时检查核心区、海岸和贸易路线。

## 建造与单位数字键

按数字键，将光标移到合法位置或目标，再左键确认。这组键最值得优先掌握，因为它能省掉反复打开菜单的动作。

| 键位 | 装填内容 |
| --- | --- |
| `1` | 城市 |
| `2` | 工厂 |
| `3` | 港口 |
| `4` | 防御工事 |
| `5` | 导弹井 |
| `6` | SAM 防空发射器 |
| `7` | 战舰 |
| `8` | 原子弹——发射后保持装填 |
| `9` | 氢弹——发射后保持装填 |
| `0` | MIRV 多弹头 |

`Enter` 在光标位置确认已装填对象，`Esc` 取消预览。装填原子弹或氢弹时，`U` 会翻转发射弧线的方向。

快捷键不会绕过游戏规则。你仍需要足够金币、必要基础设施、合法位置，以及允许该单位或武器的大厅选项。

## 鼠标操作

下表采用默认鼠标方案。可在 **Settings → Left click opens menu** 反转菜单按钮。若点击行为与本文相反，先检查该选项。

| 输入 | 默认结果 |
| --- | --- |
| 左键点击敌方或无主边境 | 攻击，跨水时派出运输船 |
| 装填建造后左键点击己方土地 | 放置建筑 |
| 右键 | v33 beta 中有战舰/船只选择时取消选择；否则打开 Radial 或 Build 菜单 |
| `Ctrl` + 左键 | 在该位置打开 Build 菜单 |
| `Alt` + 左键 | 打开表情菜单 |
| `Shift` + 拖动 | 框选多艘战舰 |
| 滚轮 | 缩放 |
| 中键拖动 | 平移视野 |

不要把 `Shift` + 拖动理解为重复建造。默认参考中，它用于框选战舰。只有已装填核弹具有本文描述的连续发射行为。

## 视野与镜头键

| 键位 | 行为 |
| --- | --- |
| `Space` | 切换地形与国家视图 |
| `M` | 开关坐标网格 |
| `C` | 将镜头居中到自己国家 |
| `Q` / `E` | 缩小 / 放大 |
| `+` / `-` | 备用缩放 |
| `W` `A` `S` `D` | 平移镜头 |
| `P` | 暂停 / 继续 |
| `,` / `.` | 单人模式减速 / 加速 |

把 `C` 当成镜头恢复键。远距离查看海战或核目标后，一次按键就能把注意力拉回自己国家。

`Space` 不只是视觉效果。不同视图会让地形或领土归属更容易辨认，适合在投入部队前快速检查。

## 战斗、外交与工具键

| 键位 | 行为 |
| --- | --- |
| `T` / `Y` | 降低 / 提高攻击比例 |
| `B` | 朝目标发起船只攻击 |
| `G` | 朝目标发起地面攻击 |
| `Shift` + `R` | 反击最近攻击你的玩家 |
| `F` | 选中全部战舰 |
| `Shift` + 拖动 | 选中局部战舰群 |
| `U` | 翻转已装填原子弹或氢弹的弧线 |
| `K` | 向悬停玩家请求同盟 |
| `L` | 解除同盟 |
| `Alt` + `R` | 重置图形 |
| `Esc` | 关闭菜单或取消建造预览 |

v31 版本笔记把 `K` 和 `L` 作为更快的外交操作。战场需要立即决定时，它们能避免再打开一层菜单。

谨慎使用 `Shift` + `R`。它针对的是最近一次攻击者，不一定是当前最危险的对手。

## 什么时候用快捷键，什么时候用菜单

已经做出决定时用数字键。确定需要防御工事后，按 `4` 能把更多注意力留给兵力、边境和飞来的投射物。

仍在比较选项时用 Radial 菜单。它能显示可用建筑和二级选项，处理不熟悉的升级时更稳妥。

只想快速查键位时，打开[快捷键总表](/zh/shortcuts/)。本文更适合学习判断、练习流程和故障恢复。

| 场景 | 推荐操作 | 原因 |
| --- | --- | --- |
| 放一座熟悉建筑 | 数字键后点击 | 动作最少 |
| 连续攻击多个核目标 | `8` 或 `9` 后连续点击 | 核弹保持装填 |
| 不熟悉的升级 | Radial 菜单 | 可视化确认 |
| 镜头迷路 | `C` | 返回自己国家 |
| 精细调整攻击比例 | 滑块 | 视觉更精确 |
| 快速调整攻击比例 | `T` 或 `Y` | 鼠标留在前线 |
| 多艘战舰 | `F` 或 `Shift` + 拖动 | 进行编组控制 |

## 十分钟练习流程

建议在单人模式练习，这样可以使用 `P`、`,` 和 `.`。目标不是赢，而是消除“看出需求”和“发出正确命令”之间的停顿。

### 第一步：确认默认布局

开局前打开 **Settings → Keybindings**。将数字键、镜头键和攻击比例键与本文对照，记录会影响练习的自定义映射。

同时检查鼠标设置。即使键盘绑定正确，菜单按钮反转也会改变所有建造练习的手感。

### 第二步：练习镜头恢复

用 `W`、`A`、`S`、`D` 移远，再用 `Q`、`E` 缩放，最后按 `C`。反复练习，直到回到自己国家成为本能。

观察边境时按 `Space`。这样可以学会在不把鼠标移出争夺区的情况下切换信息层。

### 第三步：不用菜单建造

按 `1` 装填城市，放置后按 `Esc`。只有在对象可用且付得起时，才继续练习 `2` 到 `6`。

每次放置后观察预览是否仍存在。普通建筑会在一次放置后清空，识别这个差异能避免误造第二座。

### 第四步：练习边境控制

把光标放在安全边境，按 `T`、`Y` 观察攻击比例变化，再用 `G` 或普通点击发起一次有意识的地面攻击。

不要乱按比例键。先把方向与效果对应起来，再在下一次攻击前回到已知的投入水平。

### 第五步：练习海军选择

有战舰时按 `F` 选中全部。取消后再用 `Shift` + 拖动，只框选本地一组。

两种命令解决不同问题。`F` 是全局响应；框选可以让另一处港口或海岸保留守军。

### 第六步：安全练习核发射

在允许核弹的大厅中，建好基础设施并攒够金币。按 `8`，点击一个合法目标，确认原子弹仍保持装填。

不再按 `8`，直接移动到第二个目标。随后按 `Esc`，确认下一次点击不会继续发射。

发射前再练习一次 `U`，熟悉弧线翻转。这个练习只用于掌握操作，不代表某个弧线方向永远更优。

## 实战操作序列

下面是记忆模板，不是固定建造顺序。花钱前仍要检查金币、地形、大厅规则和威胁。

### 快速加固边境

1. 镜头偏离时先按 `C`。
2. 移到受威胁边境。
3. 按 `4` 装填防御工事。
4. 让 30 tiles 范围覆盖实际进攻路线。
5. 若预览仍存在，按 `Esc` 清空。

第一座防御工事成本 50,000 金币，在范围内提供 `mag ×5`、`speed ×3`。快捷键只节省菜单时间，覆盖是否有效仍由位置决定。

### 不丢前线的经济检查

1. 让鼠标留在边境附近。
2. 按 `C` 查看核心区。
3. 用 `1`、`2` 或 `3` 放置计划中的城市、工厂或港口。
4. 用镜头键回到前线。
5. 只有局势变化时才用 `T`、`Y` 调整比例。

这个节奏把“经济决策”和“机械执行”分开。先决定买什么，再用快捷键降低放置时的注意力消耗。

### 核弹齐射与正确取消

1. 确认大厅允许核弹。
2. 检查武器、金币和目标。
3. 原子弹按 `8`，氢弹按 `9`。
4. 每个计划目标点击一次。
5. 最后一发后立刻按 `Esc`。

取消是发射流程的一部分。武器仍装填时，后续查看、移动或切回地面操作的点击都可能变成昂贵误操作。

### 海岸响应

1. 整支舰队都要响应时按 `F`。
2. 只动一组时用 `Shift` + 拖动。
3. 用中键或镜头键移动视野。
4. 让剩余战舰继续守住原来的海岸。

v31 加入多战舰选择和撤退行为。选择更快只有在你没有抽空其他航道时才有价值。

## 数字例子：操作快不等于决策值钱

快捷键本身免费，但执行的动作不免费。城市基础成本 125,000 金币，每级增加 250,000 人口上限。快速按 `1` 不会让一座多余城市变划算。

原子弹成本 750,000，氢弹成本 5,000,000。首枚 MIRV 成本 25,000,000，此前每发射一次，再增加 15,000,000。

一次误按 `9` 的花费相当于六枚原子弹再加 500,000 金币。连续发射结束后，务必把 `Esc` 作为最后一步。

导弹井成本 1,000,000，第一座 SAM 成本 1,500,000。`5` 和 `6` 只加快放置，不会消除 2,500,000 金币的基础设施选择。

第一座防御工事成本 50,000，之后逐步升到每座 250,000。只有先确定真正的隘口，`4` 的快速调用才有高价值。

## 常见失败模式

### “按数字键没有反应”

先看 **Settings → Keybindings**，按键可能已改动或解绑。再检查金币、前置设施、大厅选项和光标位置是否合法。

没有诊断前不要反复按。缺失条件一旦满足，之前的连续输入可能突然变成意外购买或发射。

### “下一次点击又发了一枚核弹”

原子弹和氢弹发射后保持装填，这是预期行为。计划齐射结束后，按 `Esc` 或右键取消。

把完整节奏记成“武器键、目标、`Esc`”。最后的取消不是可有可无的清理动作。

### “Shift 点击没有重复建造”

默认参考并未把 `Shift` 记录为通用重复建造键。`Shift` + 拖动用于框选战舰。普通建筑每放一次都要重新按数字键。

### “左键变成了攻击，没有打开菜单”

检查 **Left click opens menu** 和光标下 tile。点击结果取决于归属、水域条件和当前是否装填了建筑。

先按 `Esc` 再排查。清空装填状态能先排除一个干扰因素。

### “全选战舰让另一侧海岸空了”

`F` 会选择整支舰队。只需要区域舰队时，用 `Shift` + 拖动。全局响应可能让另一座港口失去保护。

### “反击键打错了战略目标”

`Shift` + `R` 回应最近攻击者，不一定回应最大威胁。只有确认立即反击符合整体计划时才使用。

### “操作比对手快，经济却崩了”

快捷键减少执行时间，不会改善错误选择。无价值建筑造得再快，仍然消耗金币和注意力。

用[经济基础攻略](/zh/strategies/economy-fundamentals/)决定买什么，再回本文学习如何更快执行。

## 面对高速对手时怎么调整

对手快速连发核弹时，先想到保持装填的数字键，不要直接假设外挂。原子弹和氢弹可被 SAM 拦截；MIRV 载体不是目标，但分裂弹头按常规弹道检查拦截。

重要核心区要有重叠 SAM 覆盖，但不要把所有发射器挤进同一个爆炸区。具体取舍见[核威慑攻略](/zh/strategies/nuclear-deterrence/)。

对手在一条边境高速建造时，先慢一秒。检查地形、防御工事覆盖和攻击比例，再决定是否跟随其节奏。

自定义键位冲突时，把高频动作放在易操作的位置。至少保留明确的取消键、镜头恢复键、攻击比例键和常用建造数字键。

大厅禁用核弹时，`8`、`9`、`0` 的决策消失。把注意力转向镜头、防御工事、城市、港口、工厂和战舰。

## FAQ

### 对手为什么能那么快连发核弹？

按一次 `8` 或 `9` 后，可以直接点击多个目标。原子弹和氢弹每次发射后仍保持装填，不需要任何外部工具。

### 怎样停止连续发射？

最后一个目标后按 `Esc` 或右键。回到普通点击前，确认装填预览已经消失。

### `Shift` 能重复建造所有建筑吗？

不能。默认记录中的 `Shift` 鼠标操作是框选多艘战舰。普通建筑每次放置后都要重新装填。

### 能重映射全部快捷键吗？

v33 参考确认，全部按键都可以在 **Settings → Keybindings** 中重新映射，部分操作也可以解绑。

### `U` 有什么作用？

它翻转已装填原子弹或氢弹的发射弧线，不会改变爆炸范围，也不会让武器免疫 SAM。

### 怎样最快把镜头拉回自己国家？

按 `C`。远距离查看海战、核目标或地图另一端后，都可以用它恢复位置。

### 战舰该用 `F` 还是框选？

全舰队响应时用 `F`。另一处海岸、港口或水道仍需要本地守军时，用 `Shift` + 拖动。

### 暂停和速度键能在多人局使用吗？

默认参考把 `,`、`.` 记录为单人速度控制。不要把多人应对建立在暂停或改变全局速度上。

### 为什么不同 tile 上左键行为不同？

点击行为取决于上下文。它会根据位置和装填状态，执行攻击、运输或建筑放置。
