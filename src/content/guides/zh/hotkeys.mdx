> 下文均为**默认**布局。v24 起所有键位都可在 **Settings → Keybindings** 重新映射，部分键还能完全解绑。macOS 上把 `Ctrl` 读作 `Cmd`。

## “对手核弹为什么发得这么快？”

几乎每个新手最后都会问这个问题。答案是**不需要任何外挂或连点器**——靠的是两个内建机制：

1. **建造数字键能瞬间装填一个建筑/单位。** 按 `8`，光标上立刻就托着一颗原子弹——不用召出 Radial 菜单，也不用层层点选。左键点目标即发射。
2. **核弹发射后会保持装填状态。** 当你放下原子弹（`8`）或氢弹（`9`）后，建造“预览幽灵”仍留在光标上，于是你只要不停左键点不同目标，就能一颗接一颗地砸下去。按 `Esc` 或右键即停止。

所以你在别的 RTS 里记得的“按住 Shift 点击重复”在这里并不是同一个键位——但对核弹来说等效操作更简单：**点一下 `8`，然后连点、连点、连点。** 其余建筑放置一次后幽灵就清空，所以每造一个就要重按一次数字键。

## 建造 / 单位热键

按数字键，再左键点你想放的位置。这能完全跳过 Radial 菜单，也是高手在后期狂建建筑（与核弹）的方式。

| 键位 | 建造 |
| --- | --- |
| `1` | 城市 |
| `2` | 工厂 |
| `3` | 港口 |
| `4` | 防御工事 |
| `5` | 导弹井 |
| `6` | SAM 防空发射器 |
| `7` | 战舰 |
| `8` | 原子弹 —— **发射后保持装填，可连发** |
| `9` | 氢弹 —— **发射后保持装填，可连发** |
| `0` | MIRV 多弹头 |

- `Enter` —— 在光标所在处建造已装填的单位（替代点击）。
- `Esc` —— 取消建造预览。
- `U` —— 翻转已装填原子弹/氢弹的发射弧线方向（朝上 / 朝下）。

| 操作 | 结果 |

| 左键点敌方 / 无主边境 | 发起攻击，跨海则自动派出运输船 |
| 已装填建造时左键点自己领土 | 放置该建筑 |

| 拖动 Attack Ratio 滑块 | 调整每次攻击投入的兵力比例 |

| 中键拖动 | 平移视野 |

## Radial 菜单（v24 重做）

右键自己土地召出。现已是多级菜单：核心建筑在环上，SAM、工厂、战舰与升级选项在二级菜单。

```
       Build City
            |
    Port -- ⊕ -- Defense
            |
       Missile Silo
```

刚学图标时 Radial 菜单很好用——但一旦你清楚要造什么，**上面的建造数字键要快得多**。

## 操作组合

- **核弹齐射**：`8` → 依次点每个目标（原子弹保持装填）。要氢弹就切到 `9`。
- **海岸防御**：`3`（港口）→ 放置，再 `4`（防御工事）→ 紧贴港口内侧塞进去。
- **速铺经济**：`1`（城市）→ 点空地；幽灵清空后再按一次 `1` 造下一个。
- **同盟**：悬停对手按 `K`，或点其头像 → Request Alliance。

## 实战节奏

熟练玩家的鼠标动作大多在三处轮转：

1. **自己土地的中部** —— 建造与升级（如今多用数字键）。
2. **边境** —— 攻击与运输。
3. **小地图 / 玩家列表** —— 看对手扩张曲线。

无论操作风格如何，核心是<strong>不要离开战场视野</strong>——OpenFront 节奏快，离开 10 秒可能就是一座 City 易主。
