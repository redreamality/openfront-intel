## 直接答案：别做国家打击区间里那个便宜的目标

在 `v0.35.0-beta1` 中面对 Hard 或 Impossible 国家时，一旦你进入它们的打击区间——也就是你的兵力大致等于国家当前兵力一半的那个区域——就要停止扩张，因为它们会先用核弹消耗你，然后在核弹命中的同一 tick 发起后续进攻。把国家沿边境修建的防御工事当作预警信号，把你最有价值的建筑放在纵深而不是接触线上，用 SAM 覆盖你的核心让核弹落空，并且只在国家已经投入兵力的时候才反击。一句话：不要呈现一个便宜、贴近、高价值的目标。单靠习惯恰恰是 v35 国家惩罚的东西，下面整篇指南就是围绕这一条习惯展开的纪律。

这一条习惯比任何单个反击选项都更重。v35 的国家不是一个总是挑最弱邻居的固定脚本，而是一连串类人决策，最终收敛为一次「原子弹-然后-进攻」的联合动作。如果你的扩张把自己的兵力正好压在这条半兵力线上，你等于递给它一个能通过其资格测试的目标。如果你撤退、把价值放在缓冲带后面、让核弹落在空地或低价值土地上，后续进攻就没有可收拾的东西。下面其余内容——核弹数学、关系变化、防御工事信号、机器人吞并经济——都是告诉你何时以及如何运用这一条习惯的背景。在下次吞并前用下面的 **S-T-R-I-K-E** 框架检查：核对 **S** 兵力区间、观察 **T** 预警、记住 **R** 关系不再惩罚反击、**I** 隔离你的价值、**K** 打掉后续部队、选择你的 **E** 撤退或反击。

每个字母都是一次吞并前必须完成的检查。**S** 兵力：如果下一次吞并会把你推到国家当前兵力的至少一半，停下——你现在对打击有暴露。**T** 预警：如果国家沿这条边境布置防御工事，预期几分钟内这条边境会有打击。**R** 关系：在 Hard 和 Impossible 中，防御性反击不付出升级代价，所以打击来袭部队，但别把它变成消耗战。**I** 隔离：下一座高价值建筑要建在接触线后一条缓冲线上，而不是建在接触线上。**K** 打掉：保留一支足以对抗国家后续部队的明确预备队，因为核弹花掉了它的载荷，让它的兵力变薄。**E** 撤退：如果你已经在区间内、暴露着价值、预警正在进行，把部队撤到缓冲带后面并收紧 SAM 核心，在国家的储蓄成熟之前。如果某处阵形六项检查里有三项及以上是「差」，吞并那座建筑就不值得；转而吞并下一条边境上更便宜的那个。

## v35.0-beta1 改了什么，以及你读到的版本边界

这篇指南明确是为 `v0.35.0-beta1` 这个 beta 状态写的，该状态以 PR #5899 交付了 AI 重构，标题为「国家玩起来更像会赢的人」。beta tag 是这里描述的行为确切存活的位置：tag commit 是 `ab5cc61`，国家 AI commit `fac309acc` 在 tag 下方十六个 commit 处，所以本文引用的常量是打了 tag 的源码，不是草稿也不是回填。把这篇当作 beta 边界来读，而不是最终版。OpenFront 处于 early access，v0.35.0 系列在这条 beta 和最终发布之间还可能变化；所以如果游戏里看到的数字与本文不符，以游戏和更新的发布说明为准，并报告偏差。

这次重构覆盖面广，但决定决策的核心只有一个：Hard 和 Impossible 国家现在执行一套**打击协议**。它们挑选一个与自己大致等强的相邻对手，朝它扔核弹，然后在核弹命中的同一 tick 发起后续进攻，让爆炸制造伤害、进攻只负责清扫。围绕这单一改动，该 PR 又提供了四个伴随行为，它们重新定价了你的反击和暴露。第一是**关系**：反击一个国家不再在 Medium、Hard 或 Impossible 上激怒它（只有 Easy 保留旧的升级行为），而且只有*手动*禁运才会降低关系——这让纪律反击和贸易干扰比 v34 便宜得多。第二是**防御工事**：现在建造在足够靠后的位置保证按时完工，而且 Hard 和 Impossible 在进攻一条敌方边境*之前*会额外加固它——这是一个可读的信号。第三是**机器人吞并**：Hard 和 Impossible 会按一个把其他玩家围困在内的顺序吞并机器人，从而免费获得这些玩家，而且只派出一次机器人进攻所需的最小兵力。第四是**经济**：国家更晚开始储蓄、储蓄期间继续建设收入建筑、拒绝为会挡掉自己 SAM 的 MIRV 储蓄、优先在海岸修港口、一次性购买多级升级。纯水国家不再存在，Impossible 领袖也不再仅仅为了那个位置就核平二号玩家。对决策真正重要的差异，并排列出：

| 行为 | v34 | v0.35.0-beta1 (#5899) |
|---|---|---|
| 反击引发的升级 | 在所有难度上激怒国家 | Medium、Hard、Impossible 不再激怒；仅 Easy 保留 |
| 降低关系的动作 | 被动贸易可能使其恶化 | 只有手动禁运会降低 |
| 防御工事时机 | 常常太晚建好 | 按时建好；Hard 和 Impossible 在进攻前加固目标边境 |
| 核弹序列 | 按自己节奏进攻 | 核弹-然后-进攻，落在核弹或最后 MIRV 弹头命中的 tick |
| 机器人进攻 | 一支完整军队 | 最小必需兵力；Hard 和 Impossible 的顺序会围困其他玩家 |
| 反制核弹 | 无或罕见 | 国家会核平那些炸弹正朝它飞行的玩家 |
| 储蓄期间的经济 | 停止建设收入 | 继续建设收入、更晚储蓄、一次买多级升级 |
| 纯水国家 | 可能存在 | 不再存在 |

下面每一节都是对其中一项改动的玩家视角解读。

## 打击协议：大致等强、消耗、然后在命中时进攻

这次改动的核心是三个合起来定义**打击区间**的数字。国家只在目标拥有**至少国家当前兵力一半**时才考虑一次打击——源码常量是 `STRIKE_MIN_TROOP_RATIO = 0.5`。这就是「大致和自己一样强」的那条线。一个你可以轻松碾过去的弱小邻居不符合打击资格，它落入普通地面进攻的范畴。一个比你大五倍的国家，按这个测试*不是*在核平你，而是可能只是简单地向你扩张。打击保留给规模可比的对手。

第二个数字是后续要求。在 Hard 和 Impossible 中，即使目标过了半兵力线，国家也必须能发起一支**至少相当于目标兵力一半**的后续进攻才会打击——`STRIKE_MIN_STACK_RATIO = 0.5`。所以一次打击是一项*承诺*，不是垃圾攻击：国家会检查爆炸后的进攻仍有牙齿。如果国家在别处被牵制、可自由支配的兵力很少、或爆炸让它可以少送后续部队，它就会保留核弹。第三个数字是距离：国家在爆炸和自己领地之间保持**10 格边距**（`STRIKE_BORDER_MARGIN = 10`），这样它用于后续进攻的战线才能扛过爆炸、部队还能抵达你。打击还会等待约 10 tick（`STRIKE_SPAWN_TICKS = 10`）直到核弹生成后再投出。

把三者组合起来，可以把一次打击读成一个可以部分打断的两段动作。第一段是核弹，制造伤害但不暴露国家任何兵力。第二段是在核弹（或 MIRV 的最后一个弹头）命中的同一 tick 发起的后续进攻。国家在源码里的自评很明确：MIRV 让先手方「几乎没有部队可以防御」，这正是你必须打断后续进攻而不是核弹本身的原因。所以你的反击瞄准第二段：顶住后续部队，或把爆炸引向它的伤害打不开任何后续进攻能利用的缺口的位置。MIRV 的行为类似但赌注更高：因为 MIRV 把载荷投进多个弹头，先手国家背后几乎没有部队，所以一次时机恰当的反击打进被清空的边境，能在最后一个弹头落地前赢得交换。这是 v34 以来最重要的重排：核弹是准备，后续进攻才是杀手。

## 读懂爆炸：覆盖、边距，以及一枚浪费的核弹在说什么

国家核平你不是为了造成伤害，而是当爆炸*划算*时才核平你。源码编码了一个爆炸必须落在敌方土地上的最小比例——`MIN_BLAST_COVERAGE`——且随核弹类型变化：**原子弹**需要至少 **0.25**（四分之一）的爆炸落在你的土地上，而**氢弹**需要至少 **0.4**。低于这些门槛时，国家更倾向地面进攻，因为爆炸主要扫过水域、辐射区或中立土地，后续进攻就无物可扫。这对你是一个具体杠杆：如果你的暴露面积小、且大部分在开阔水域或辐射区后面，一枚大氢弹对你就是笔亏本买卖，国家通常会选择不打。完全只落在敌方土地上的爆炸会在国家的格子评分中获得大额加成（`FULL_BLAST_COVERAGE_VALUE = 50_000`），这就是为什么一条密集、实心、大部分敌方的边境是最差站位。

另外两个数字让爆炸数学变得可用。第一个是王冠规则：当玩家持有**超过一半未受辐射土地**时（`CROWN_NEAR_WIN_SHARE = 0.5`），*每个* FFA 国家——不分难度——都会核平王冠位置。如果你离拿下地图只差一大波扩张，就要假设炸弹飞向王冠，在越过这条线之前规划一个备用位置。第二个是密度：目标需要最低的结构等级总和（`MIN_LEVEL_SUM_FOR_HIGH_DENSITY_NUKE = 5`）才会被当作高密度核弹目标。这奖励你把*少量*高等级建筑集中在覆盖之下，而不是把大量低等级建筑摊开在边境上——一排 1 级建筑对爆炸来说清扫起来便宜，给国家一次令人心满意足的全覆盖打击；而一个高等级建筑紧凑核心藏在 SAM 伞下，才是让爆炸变得更不划算的版本。

把爆炸阅读当作**浪费核弹检测器**。如果国家投出一枚核弹但爆炸大部分打偏了你的建筑——水、辐射区或未占领的土地吞掉了半径——后续进攻很可能熄灭，因为国家是假设大片覆盖会打开你的土地才选择投弹的。当你看到爆炸落在这条覆盖率之下，就是你的信号：后续进攻很弱，一次针对软弱前线的纪律反击可能成为胜负手。反过来，当国家即使你处于打击区间也保留核弹时，把它读成对*你*的好消息：国家算出爆炸覆盖你的部分不足以支撑这次承诺，多半正在选择扩张或等待。爆炸数学就是国家自己的成本函数，它把相当一部分意图泄漏到了地图上。

## 关系变化：反击不再激怒国家

v34 及以前，Hard 和 Impossible 游戏中一大恐惧是升级：你反击国家的推进，国家就把你当作优先目标并加注。这种动态变了。在 #5899 重构中，**反击一个国家不再激怒它**（Medium、Hard、Impossible 全部如此）——旧的「激怒」升级行为在这些难度上实际被移除，只有 **Easy** 保留。与之分开来看，现在唯一会降低国家关系的动作是**手动禁运**：被动贸易姿态不再像以前那样恶化关系。实际后果：纪律反击和贸易干扰现在比 v34 便宜得多。你可以打击国家来袭的进攻、夺回一条边境，而不必假设它会出于怨恨转向你。

这并不意味着反击免费，也不意味着国家停止瞄你。国家继续走自己的正常优先级清单——反击正在打它的玩家、很弱的目标、已被施压的受害者、同盟、背叛、以及新的打击分支。如果你同时也是*当前*进攻方，那你按定义就是反击目标；变化在于*防御性*反击或*贸易*干扰不再叠加一个隐藏的怨恨乘数。指令：当你是防御方、或能短期成为进攻方时就反击，但不要把反击连成一仗把你自己长期留在国家面前的活靶子上的大规模进攻。

第二个与关系相关的行为对核防御分量很重。在 v35，**国家会核平那些炸弹正朝它飞行的玩家**。这是直接的空中反制，不是性格特征。如果你朝一个国家发射 MIRV 或氢弹，预期一枚对你的反制核弹会在你的核弹还在空中时就瞄准你，只要该国家有核弹可用。源码规定 Hard 和 Impossible 国家在为自己的 MIRV 储蓄期间*只*会动正在打它们的玩家，且用原子弹。所以你抽到即时反制核弹概率最低的窗口是国家的核弹尚未准备好之前；概率最高的窗口是你对它发射的那一刻。安排你的发射时机，让国家的核弹被牵制或不可用；永远别假设一次发射是单行道。

## 防御工事预警，以及你的 SAM 暴露

这次重构中最可读的早期预警信号是**防御工事预警**。源码把国家的防御工事布置在足够靠后的位置，保证在它们要防御的那次进攻到来前建好；Hard 和 Impossible 还会在进攻*之前*额外加固通向敌方邻居的那条边境。翻译成玩家语言：当国家开始沿一条即将打击的边境精确地建造防御工事时，那条边境上的一次打击或大进攻迫在眉睫。观察建造队列和布防位置，而不只是兵力数字。一个国家突然朝你的边境排出一线防御工事，就是在地图空间里告诉你它下一步大动作的方向。

同一改动的另一面是你自己的**SAM 暴露**，这里的数字是必须记住的。国家每座城市建造的 SAM 炮随难度缩放——`SAM_RATIO_BY_DIFFICULTY`：**Easy 0.15、Medium 0.20、Hard 0.25、Impossible 0.30**。Impossible 国家的 SAM 伞因此明显比 Medium 更密，而且当它任意一座建筑已有覆盖时它会*升级*这些 SAM（`SAM_UPGRADE_WHEN_COVERED` 行为），而不是继续铺新炮。对你的含义：终局的一条 Impossible 边境是一堵升级过的 SAM 墙，朝国家核心扔核弹就是亏本买卖。你自身的 SAM 预算应当按*让国家的爆炸落空*来定标，而不是去镜像它的数量。把 SAM 集中在缓冲线后高等级建筑的紧凑核心上，这样当国家投弹时爆炸会被拦截或在射程内被截断，`MIN_BLAST_COVERAGE` 测试失败。

两个相关的经济数字收紧了暴露窗口。国家储蓄期间，其收入建筑的感知成本按难度下调——`INCOME_STRUCTURE_SAVING_WEIGHT`：**Hard 0.6、Impossible 0.4**——意味着 Hard 和 Impossible 在为大目标储蓄期间继续建设收入，所以它们的金钱和建筑数*在储蓄期间继续增长*。而且一个国家最多持有 **3 座导弹井**（`MAX_MISSILE_SILOS = 3`），第一座的城市比例为 **0.4**（`FIRST_MISSILE_SILO_RATIO = 0.4`）。所以你的核防御规划可以锚定一个上限：国家永远不会超过三座井，而*第一*座相对它的城市数出现得相当早。把你的 SAM 覆盖建到让国家第一或第二座井不值得被拦截，因为之后它几乎没有核余量了。

## 机器人吞并，以及你要阅读的经济

机器人吞并的改动关系到国家在冲向你的同时*还在吃谁*，以及它如何改变盘面。Hard 和 Impossible 国家**按一个把其他玩家围困在内的顺序吞并机器人**，这样被围困的玩家在失去开放边境后*免费*被吞并。它们也只派出**一次机器人进攻所需的最小兵力**，而不是完整军队。对你的两个后果。第一，那些你可以安全消耗的「安全」中立机器人，常常被国家按特定顺序吃掉，*把你*封在它们后面——当你和国家争抢同一批机器人时，国家可能故意留着一个机器人来围困你。把国家的机器人顺序读成一张它要关闭哪些边境的地图。第二，因为国家只在机器人上花最小兵力，留给*真正*打击你的兵力池更大——正是 `STRIKE_MIN_STACK_RATIO` 后续测试抽取的那个池子。

经济改动是你所对抗的另一半盘面。国家**更晚储蓄、储蓄期间继续建设收入**，意味着它的开局更偏扩张、储蓄窗口比 v34 更晚——你的危险不在开局几分钟，而在中后期它储蓄窗口成熟时。它**拒绝为会挡掉自己 SAM 的 MIRV 储蓄**，所以被你 SAM 覆盖的国家更少会投资一枚指向你的 MIRV。在**海岸**它*更少*地用工厂换港口（海岸工厂倍率随难度上升：**Easy 0.33、Medium 0.45、Hard 0.55、Impossible 0.60**），在**团队赛中**从一开始就建更多港口（`TEAM_PORT_RATIO = 1`，非团队赛 `0.75`），因为队友是安全贸易伙伴。一次买多级升级、加上高初始金钱的停止修复，意味着国家的建筑等级以波次而非渐进方式跳升，所以国家突然的等级跳升波是一个信号：储蓄窗口成熟、它即将成为对你实际的（而非你预测的）兵力的活打击威胁。实操读法：跟踪国家的金钱-建筑比例和海岸港口/工厂配比，把一次多级跳升当作你必须在它进入你要避免的打击区间前收拢缓冲带的时刻。把一个仍然敞开的储蓄窗口当作建设你自身缓冲带和 SAM 的时间窗口，而不是扩张的时间窗口，因为国家金钱和建筑等级在储蓄期间继续爬升，它关上储蓄窗的那一刻就是它成为活打击威胁的那一刻。

## 场景一：FFA 边境上，Hard 国家兵力约等于你的一半

用具体数字摆出场景。你在一局 FFA 中对 Hard 国家。你有 **1,200,000** 兵力；Hard 国家有 **2,400,000**。你恰好压在一半——你正处于打击区间，因为 `STRIKE_MIN_TROOP_RATIO` 要求目标至少达到国家兵力的一半，而 1,200,000 正是 2,400,000 的一半。你的边境上有四座 3 级城市和两座 2 级港口，一个紧凑核心，一条干净的地面接触线通向国家。国家有 2,400,000 兵力，刚处理完自己的机器人队列，有大量可自由支配的兵力。假设它有一枚原子弹可用、没有其他核弹。

对这个阵形跑一遍 **S-T-R-I-K-E**。**S** 兵力：你正压在线中央——差。**T** 预警：国家刚沿你的接触线部署了一线防御工事，那是「进攻前加固」信号——差。**R** 关系：你没打过它、它也没被你禁运，所以防御反击不付升级代价——中性，但意味着你可以*便宜*地反击。**I** 隔离：你的四座 3 级城市和两座港口*就在*接触线上、不在纵深后——差，它们正是国家想要的那种密集、实心、大部分敌方的爆炸。**K** 打掉：国家能发起一支远超你 1,200,000 一半的后续部队，后续测试通过——差。**E** 撤退：诚实的走法是*不该*站在这里。正确走法：硬停这条边境——在国家的储蓄窗口成熟之前把边境城市和港口撤回接触线后一条缓冲线，把 SAM 集中在紧凑核心上，让原子弹的 `MIN_BLAST_COVERAGE` 测试失败（原子弹需要四分之一的爆炸落在你的土地上），保留一支明确预备队，这样当国家投入后续部队时你有兵力顶住软弱前线。如果你无法撤，出路是让爆炸打偏：把你的暴露面积大部分留在开阔水域或辐射区后面，让国家本该打出的全覆盖加成无从产生，把反击留给后续部队到达的 tick——那时它的兵力被牵制、它自己的前线就是你能够打破的那 10 格边距。场景的教训：在国家兵力的恰好一半、把你最好的建筑放在接触线上，是 v35 惩罚的那一种最差的阵形。

## 场景二：Impossible 单人 / HvN——顶住 MIRV 后续

现在看更硬的终局。你在一局 **Impossible** FFA 或 Humans-vs-Nations 中。只剩两个大国：你和 Impossible 国家。你有 **900,000** 兵力；国家有 **1,800,000**——又是半线。国家已完成建筑：最多 **3 座导弹井**，它已在你的边境部署了一枚 **MIRV**。它的 SAM 伞密（每城 0.30 SAM、有覆盖即升级），所以朝*它*的核心扔核弹是亏本买卖。MIRV 是威胁：MIRV 把载荷投进多个弹头，所以在最后一个弹头落地那一刻国家「几乎没有部队可以防御」——但后续进攻在最后弹头命中的 tick 启动，而 Impossible 中 `STRIKE_MIN_STACK_RATIO` 仍要求它能发起你 900,000 的一半、即 450,000，它仍发得出来，因为它留了核心兵力。

这里的顶法不同于场景一。你没法逐个 SAM 掉 MIRV 的弹头；你必须**顶住后续部队和命中几何**。第一，把你的价值保持紧凑、放在纵深，这样你无法完全拦下的那些弹头落在低价值或半低价值土地上，压低国家用来给这次打击计分的 `FULL_BLAST_COVERAGE` 价值。第二也是最重要的：把你自己的 900,000 *不要*绑在暴露的边境上：把大多数保留为 SAM 核心后的明确预备队，这样当最后弹头落地、国家后续进攻以薄弱前线压上来时，你打向的是*被清空的*国家边境边缘，而不是 MIRV。因为国家已花光核载荷，它这次交换的反制核弹已耗尽，而 MIRV 让它背后几乎没兵，你 900,000 的预备队在后战中常常是更强的力量。第三，利用关系变化获利：你的反击是对*被牵制*国家的防御性反击，Impossible 上不付升级代价——你不是在「激怒」它，你是在它的后续部队已投出之后打它。场景的教训：对 Impossible 的 MIRV，你不靠拦下核弹取胜，你靠保住兵力、让爆炸打空、然后在后续部队投入时立即打击被清空的边境取胜。如果 MIRV 分裂成多个弹头，优先守住你*真正*要守的那条边境，而不是守住每一座暴露建筑，因为 MIRV 载荷覆盖的地理比单枚核弹更大，你的预备队只需要在你承诺的那条线上顶住后续部队；其他线可以让掉，只要 SAM 伞下的紧凑核心扛住命中。

## 错误模式，以及能修复它们的反制

最常见的 v35 错误模式是**扩张到恰好压在半线上**——你把兵力推到国家规模的一半，因为「多一城」显得安全，然后你就站在打击区间里、兵力被钉在那里。修复是框架里的**停止线纪律**：预先定义一个你停住边境的兵力比（显著低于一半），把越过它当作一条硬边界而不是软边界。第二个错误模式是**把最好的建筑留在接触线上**。v35 国家在密集、实心、大部分敌方的边境上打出全覆盖爆炸得分，所以你的高价值城市和港口应放在纵深、而不是边缘。修复是**缓冲带后的紧凑核心**：一小簇高等级建筑放在你的 SAM 伞下，让边境保持低价值。第三个错误模式是**无视防御工事预警**。一个国家朝你的边境排出一线防御工事，就是它在该方向上的承诺；修复是把这种布防当作警报，要么撤回暴露价值，要么在打击成熟前预收紧你的 SAM 核心。

第四个错误模式是**假设一次核弹是单行道**。v35 中国家会核平那些炸弹正朝它飞行的玩家，所以朝它发射会招来反制核弹。修复：只在国家核弹被牵制、耗尽或不可用时发射，并保留备用位置，让反制核弹无法抹掉你的王冠。第五个错误模式是**把关系变化误读成「反击免费」**。防御性反击便宜；一个*连环进攻*把你留在国家面前的活进攻方，按定义仍是反击目标。修复：反击然后解除投入，别把反击变成消耗战。第六个错误模式是**过度投资 SAM 去镜像国家**。你不需要镜像它每城 0.25–0.30 的数量，你只需要足够 SAM 让国家的爆炸 `MIN_BLAST_COVERAGE` 失败，所以集中到紧凑核心上而不是摊开。第七个、最微妙的是：**把 beta 数字当成最终值**。这些是 `v0.35.0-beta1` 数值，最终发布前还会移动；修复是把行为*结构*（区间→消耗→后续、预警、反制核弹）当作稳定项，把精确常量当作需要随每次新发布说明重新核验的项。

## 模式与地图调整，以及验收测试

策略随模式变化而更锐或更钝。**FFA** 中王冠规则生效：你一旦超过一半未受辐射土地，每个国家都会核平王冠，所以在寻求胜利之前规划第二位置。**团队赛**中国家建更多港口（比例 1.0）且先支援正在战斗的队友再打结构最厚的敌人——你队内的国家因此是你要保护的港口和贸易伙伴，敌方国家优先打正在战斗的队员，这改变了你该用核弹和 SAM 覆盖谁。**Humans-vs-Nations** 中 Impossible 国家是一个带最多三座井、密集升级 SAM 伞的协调单一对手，所以场景二的 MIRV 顶法就是主终局，你整个游戏就是带着紧凑、缓冲良好的核心活到中后期，而不是摊开的、暴露的。**无同盟** 房间中国家仍然活跃、关系变化仍然生效，所以预警和反制核弹在外交关闭时同样成立。

**地图形状**上，爆炸数学是主导变量。在你的边境沿**海岸或开阔水域**延伸的地图上，你可以让自己的暴露面积小且留在水线后面，让国家的氢弹 0.4 覆盖测试失败——大氢弹扫一片平坦、大部分是水的土地是笔亏本买卖，它常常拒绝。**陆地接触**长而无缓冲的地图上，你呈现的正是国家要得分的全覆盖爆炸，所以第一个任务是创造纵深（后方第二线、建缓冲带），然后再想进攻。**紧凑**地图上边境短，10 格边距占边境很大比例、后续部队对国家更容易发起，所以停止线纪律分量更重；**开阔**长海岸地图给你更多空间让爆炸自废。

这篇指南的**验收测试**很具体，你可以在自己的地图上执行：你现在能否说出你停住国家边境的那个兵力比，且这个比例安全地*低于*国家当前兵力的一半？你知道你的哪些建筑在 SAM 伞下、哪些暴露在接触线上吗？你能把国家的防御工事线读成意图方向，并能判断它的下一枚核弹在你的布局上能否通过它自己的 `MIN_BLAST_COVERAGE` 测试吗？如果四项都能答，你就不是 v35 国家惩罚的那个便宜目标，并且你在它投入时的后续顶法已就位。更广的行为树、建筑、同盟和核弹分支见参考 [国家 AI 机制](/zh/mechanics/nations/)；本 build 所改的 v34 压力模型见 [国家压力](/zh/guides/nations-pressure/)；先核平谁的选择用 [威胁评估](/zh/guides/threat-assessment/) 和 [MIRV] 指南；你自己核弹预算背后的数字用 [核弹计算器](/zh/guides/nuke-calculator/)。
