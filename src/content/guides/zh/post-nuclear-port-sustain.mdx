核爆之后的阶段，胜者几乎总是*收入更高*的那一方，而不是最后造出一艘战舰的那一方。v0.34.12 的强化让港口与贸易的回本更快，也把 meta 推向"收入优先"的终局。本指南把这次转变变成一套决策流程：什么时候停止买军事、开始买收入；如何保持一条能扛住氢弹的 SAM 防线；以及如何在 1v1 中靠收入压过对手、或把 1v2 拖进你能赢的慢速消耗，直到加时或末日钟结束比赛。

## 核爆之后阶段究竟是什么

核爆之后的阶段，是"核弹格局已定"与"僵局解局器分出胜负"之间的那段窗口。具体说，它从每个主要玩家都放下了导弹井开始（或冷战对峙冻结、谁都不愿意先发射），到加时或末日钟强制分出胜负结束。在一场典型的三到四玩家对局里，这段窗口是最后两到四分钟的活跃期，但它是整场比赛杠杆率最高的窗口，因为你在这里做的决策决定胜者。

让这个阶段与其余比赛不同的，是*核弹答案*现在是对称的。你能 MIRV 第二名，第二名也能 MIRV 你。你能氢弹第三名，第三名也能氢弹你。核弹棋盘是一个带小幅不对称的相互确保毁灭博弈——不对称在于谁的 SAM 保护城市更多。这个不对称是真实的，但它是*防御性*的：它决定谁在交换中活下来，不决定谁赢。核爆之后阶段的*进攻*杠杆是*收入*：在核弹交换解决的那一刻，你每分钟能从港口、贸易路线和工厂产生的金币。收入率更高的玩家，就是能买下 SAM 防线、最后一艘战舰和终结比赛的最后推进的玩家。

这就是为什么核爆之后阶段不是一场"战斗"，而是像中期那样的一场战斗。它是一个*转化*问题：你在把中期积累的金币转化为*能撑过对手的收入率*。如果你带着 35M 金币但只有几座城市的陆地收入基础、没有港口进入核爆之后阶段，你坐着一笔一次性风投，它撑不久。如果你带着 25M 金币和一条已经在每分钟产出 5M 的港口-工厂铁路走廊，你坐着一个复利资产，它会在加时阈值收缩到 35% 领地之前压过那 35M。整篇指南就是关于做出第二种进入。

核爆之后阶段还有一个*形状*问题，我们会在失败模式一节回到：1v1 的核爆之后是干净的收入赛跑，但 1v2 的核爆之后（你是夹在两个更大玩家之间的中间玩家）是一个高风险形状，收入赛跑*如果*足够早承诺仍然能救你。中间玩家最容易被两面夹击，也是最可能被协同 MIRV 的目标。收入策略是*唯一*在两种形状下都有效的策略，这就是为什么它是默认，为什么其他策略（全速进攻、过度堆 SAM、无视贸易强化）至少有一种形状会失败。

最后，核爆之后阶段是*僵局解局器*成为主导考量的时候。如果房间宣布加时，收缩的领地阈值就是时钟，收入策略必须转向领地转化（在争议边缘建城市，而不是港口）。如果宣布末日钟，上升的领地份额线（v0.34.19 FFA 的 40% / 45% / 50% / 55% / 60%）就是时钟，收入策略必须保持 SAM 防线存活，让你扛过各波、赢得随后的 1v1。读出房间用的是哪个解局器是本指南其余部分的前提；如果你不知道是加时还是末日钟，就无法正确预算这次转化。如何读房间，见[末日钟对加时指南](/guides/doomsday-vs-overtime/)。

## 为什么军事支出封顶而收入复利

核爆之后阶段的核心经济事实是：军事支出有*递减*回报，而收入支出有*复利*回报。一艘战舰 250,000，给你一次性能力：它可以扫荡一块瓦片、为运输船护航、或击沉敌方贸易船。一旦对手适应（海岸的 SAM、第二艘战舰、不同路线），战舰的边际价值降到零。一枚 SAM 发射器 1,500,000，给你*常设*能力：它拦截氢弹直到游戏结束。但 SAM 的价值也是*被动*的：只有当有人真的朝你扔氢弹时才重要，而在冻结的核爆之后阶段，氢弹往往没有来。*唯一*复利的支出是港口、城市和工厂：它们每存在一分钟就产出金币，而金币买下更多同类，或买下 SAM 防线，或买下最后一艘战舰。

具体看结构成本（来自生成数据，截至 v0.34.x 线当前）：港口 125,000、城市 125,000、工厂 125,000、防御哨所 50,000、导弹井 1,000,000、SAM 发射器 1,500,000、战舰 250,000。注意跨度：港口和城市、工厂同价，但港口*新增*一个收入来源（贸易船），城市只新增陆地收入。SAM 是港口的十二倍。导弹井是港口的八倍。核爆之后阶段就是你在 125k 的复利资产（港口）与 1.5M 的保护资产（SAM）之间选择，答案几乎总是*两者都要、顺序正确*：先给港口供血，让金币到位再供 SAM。

复利论点在 1v1 里最容易看清。假设两名玩家在核爆之后阶段开始时各有 25M 金币。A 玩家花 10M 买一枚 SAM 发射器、15M 买一座城市。B 玩家花 5M 买一枚 SAM 发射器（够扛一次氢弹，这是 MIRV 赛跑线程里社区核验的门槛：6 级以上的 SAM 是氢弹无法一击摧毁的最低标准）和 20M 买两个港口加一座工厂。核弹交换解决后，A 有更强的 SAM 防线但没有新收入。B 有稍弱的 SAM 防线但有每分钟约 5M 的新收入率（两个港口加一座工厂喂养贸易路线）。到加时阈值从 50% 收缩到 35% 时，B 的收入已额外产出 30M 以上，而 A 的一次性 SAM 还坐在那里拦截从不来的氢弹。B 赢下收入赛跑，把盈余转化为领地。

同样的论点适用于 1v2，摩擦更多。中间玩家（你）有两个都更大的邻居。*军事*答案是全速进攻其中一个，但那花掉你的金币，让你听命于另一个。*收入*答案是快速建起港口-工厂走廊，快到即使你输了 1v1（因为某个大玩家 MIRV 了你），剩下的 1v1 是一场你能靠收入压过的慢速消耗。收入答案是*唯一*在被击中后*不会变差*的答案；军事答案会急剧变差。这就是为什么 MIRV 赛跑线程里的社区共识（"铁路、港口、抢贸易船，让你在终局前远超 40M"）是默认：你要带着*已经建好的*收入进入核爆之后阶段，而不是带着*之后才建*的金币。

有一个重要例外，我们会在模式调整一节回到：如果房间解局器是加时，复利论点在最后 60–90 秒*反转*，因为收缩阈值意味着领地比收入更值钱。那时你停止建港口、转向在争议边缘的城市。末日钟解局器没有这个反转；上升份额线意味着存活（SAM 防线）比收入更值钱，所以你保持港口-工厂走廊与 SAM 防线，让各波削弱对手。读出解局器因此是第一个决策，不是最后一个。

## v0.34.12 贸易船刷新强化为什么改变了 meta

v0.34.12 版本（2026 年 9 月 20 日）包含单个影响 meta 的改动："meta: 提高早中期贸易船与火车刷新率。"这就是让重贸易的"岛上人"建造走红的强化，也是核爆之后阶段现在比 v0.34 之前更奖励港口的原因。v0.34.12 之前，贸易船刷新率低到港口回本很慢，陆地收入基础（城市）通常是更好的终局收入来源。v0.34.12 之后，贸易船刷新率高到港口回本很快，贸易收入率高到港口-工厂走廊能压过纯城市基础。关于"岛上人"奇策的社区线程明确把贸易建造走红归因于这个强化："岛上人奇策最近因为贸易船上界翻倍、港口强化而走红。"

强化的实际效果有三点。第一，港口的*回本*更短。强化前，港口收入需要很长时间才能回本其 125,000 成本；强化后，更快的贸易船抵达意味着港口在少数贸易船周期内回本。第二，贸易收入的*上限*更高。贸易路线上船越多，每分钟金币越多，强化通过提高刷新率抬高上限。第三，贸易路线的*风险*更低，因为更快的刷新率意味着你能更快重建丢失的路线。这三点合起来让港口成为默认终局收入投资，工厂成为默认终局*乘数*（喂养港口铁路走廊的工厂乘以港口收入）。

强化还有一个*时机*效果。因为贸易船刷新率"早中期"提高，强化在你中期建港口时最有价值，而不是后期。中期建的港口有时间回本并复利；后期建的港口没有。这与[前置港口-工厂投资指南](/guides/frontload-port-factory-investment/)的时机教训相同：港口是前置投资，v0.34.12 强化让前置更有价值。核爆之后阶段是前置港口的*收获*；如果你没有前置，核爆之后阶段是错误的开始时间。

强化还与地图的*岛*形状相互作用。在岛地图（加那利群岛、马达加斯加、克里特、济州、斯瓦尔巴、塞布尔岛）上，港口天然被水防御：对手要登陆捕获必须穿越开阔水域，这需要他们自己的战舰护航。v0.34.12 强化让港口成为*岛屿建造的核心*，"岛上人"奇策是岛屿建造的逻辑极端：在岛中部出生，建港口和工厂，让贸易船上界做事，狙死玩家的港口以延长路线。在大陆地图（世界、非洲、中东）上，港口天然防御较弱，铁路走廊是关键：连接的大陆港口-工厂铁路线比孤立港口更难被扫荡，v0.34.12 强化让大陆地图上的铁路走廊成为默认终局投资。

强化*不*做的唯一一件事是把港口变成无敌。港口在大陆一侧仍可能被陆地扫荡捕获，在无护航的海岸瓦片上仍可能被战舰捕获。强化提高港口的*回报*，不提高港口的*安全*。安全仍来自战舰护航（250,000）、港口瓦片上的防御哨所（50,000），以及为港口供血的城市上的 SAM 防线（1,500,000）。核爆之后阶段就是同时买回报（港口、工厂）与安全（SAM、战舰护航、防御哨所），v0.34.12 强化让回报端比之前更有价值。

## 决策框架：港口、工厂、城市、SAM 的排序

核爆之后阶段是一个*排序*问题，不是一个*选择*问题。你不是在港口与 SAM 之间选择；你是在选择*买入顺序*，顺序由三个问题决定：（1）房间解局器是什么（加时还是末日钟）？（2）你当前收入率相对对手如何？（3）你当前 SAM 防线深度相对氢弹威胁如何？下面框架回答每种组合的排序。

默认排序（末日钟房间，你是第 1 或第 2，收入与对手大致持平）是：**港口 → 工厂 → SAM → 城市 → 战舰护航 → 防御哨所 → 港口（二）→ 工厂（二）**。港口第一，因为它是复利资产，125,000 成本是终局投资中最便宜的。工厂第二，因为它乘以港口收入，成本与港口相同。SAM 第三，因为它是*保护*你刚建起的收入；你想让收入先生成，再花 1.5M 买 SAM，因为 SAM 的价值是它保护的收入的價值。城市第四，因为它新增陆地收入，成本与港口相同。战舰护航第五，因为它保护港口免遭海军扫荡，250,000。防御哨所第六，因为它在港口瓦片上添加 30 瓦防御区，50,000（最便宜的终局投资）。第二港口和第二工厂最后，因为它们是*复利*步骤：第一条港口-工厂走廊开始产出后，第二条进一步乘以收入。

加时排序（加时房间，你领地领先，收入大致持平）是：**城市 → 城市 → 城市 → SAM → 港口 → 工厂 → 战舰护航**。城市第一，因为加时阈值在收缩、领地是货币。你把金币转化为争议边缘的城市，而不是港口。SAM 在城市之后，因为你需要领地第一、保护第二。港口和工厂最后，因为加时窗口短、复利论点没时间回本；只有加时阈值还足够高（40%+ 领地）你才有时间打收入赛跑时才建。

1v2 中间玩家排序（末日钟房间，你是中间玩家，两个更大邻居）是：**港口 → 工厂 → 港口（二）→ SAM → 战舰护航 → 防御哨所 → 工厂（二）→ 城市**。两个港口在 SAM 之前，因为 1v2 中间玩家的*唯一*生存策略是收入赛跑；SAM 是收入的保护，但收入才是生存。战舰护航和防御哨所在第二工厂之前，因为 1v2 中间玩家最可能被扫荡，250,000 + 50,000 = 300,000 的保护比 1.5M 的 SAM 便宜，给你 1v2 中间玩家最需要的海军防御。第二工厂在保护之后，因为它是复利步骤，1v2 中间玩家负担得起先等保护。

全速进攻排序（你是 60%+ 领地的第 1，想现在终结比赛）是：**MIRV → 战舰护航 → SAM → 城市 → 港口 → 工厂**。这是*唯一*MIRV 第一的排序，也是你不在 60%+ 领地时*唯一*错误的排序。MIRV 赛跑线程的社区共识明确："除非你握有 67% 棋盘，否则不要当恶人。"如果你在 60%+ 领地、第二名 25%、第三名 15%，MIRV 终结比赛、港口-工厂走廊无关紧要。如果你在 40% 领地，MIRV 让你成为协同氢弹的目标，你输 1v2。全速进攻是*例外*，不是默认。

框架有一条覆盖所有排序的元规则：**如果你的收入率已高出对手 20% 以上，停止建造、转向领地转化。**复利资产已经做完它的工作；下一步是把收入转化为解局器奖励的领地。元规则是理解核爆之后阶段的玩家与身处其中的玩家的差别：理解是核爆之后阶段有一次*相位转换*（收入到领地），转换的时机就是决策。

## 场景 A：1v1 收入赛跑（你是第 1，40% 领地，35M 金币）

你是三玩家对局中最大的玩家。你握有 40% 领地，第二名 30%，第三名 30%。你有 35M 金币。第二名有 25M 金币且敌对（你之前攻击过他们）。房间解局器是末日钟。v0.34.19 FFA 的末日波在 40% / 45% / 50% / 55% / 60% 领地份额。你在第一波（40%），下一波（45%）大约 60–90 秒内到来。

*错误*打法是全速进攻：MIRV 第二名，指望第三名不氢弹你。这是"当恶人"打法，错误因为你在 40% 而非 67%。如果第二名有 SAM 防线，MIRV 被部分拦截，第二名仍活在 15% 领地，第三名现在有了*动机*氢弹你（你是协同打击的目标）。你输 1v2，45% 的末日波对你削弱对手。

*正确*打法是带 SAM 防线的收入赛跑。第一步：花 1.5M 买一枚 SAM 发射器，放在为港口供血的城市集群上。SAM 的工作是扛住第二名一次氢弹；社区核验的门槛是 6 级以上的 SAM 是氢弹无法一击摧毁的最低标准。第二步：花 500,000 买两个港口加一座工厂，放在连接现有城市集群与海岸贸易路线的铁路走廊上。港口立即开始产出；工厂乘以贸易收入。第三步：花 250,000 买一艘战舰护航保护港口免遭第三名海军扫荡。第四步：花 50,000 在港口瓦片放一座防御哨所添加 30 瓦防御区。总花费 2.3M，剩 32.7M 金币与每分钟约 5M 的新收入率。

现在第二名有两个选项。选项 1：他们 MIRV 你。SAM 拦截 MIRV（或大部分），城市集群受损但未毁，港口与工厂存活。你 38% 领地、他们 30%、第三名 30%。45% 的末日波要来，你是收入率最高的玩家。波削弱对手，随后的 1v1 是你在赢的收入赛跑。选项 2：他们不 MIRV 你，45% 的末日波到来。波抽干线以下玩家（第二名和第三名在 30%、低于 45%）的领地，你在线以上。第二、三名丢领地，随后的 1v1 是你 50%+、第二名 25% 或更低。你赢下收入赛跑，把盈余转化为领地。

*假设*是这个场景中你必须核实的部分：第二名没有能绕过 SAM 的 MIRV。如果有（弹头数多到压倒 SAM 拦截能力的 MIRV），SAM 防线不够，你需要*第二枚* SAM 或*重新部署*的城市集群。检查是：数保护第二名城市的 SAM；如果他们的 SAM 多于你，MIRV 赛跑在他们一边，你*不该*全速进攻但*也不该*坐等：你应建第二港口和第二工厂，让收入率做事。其余场景是决策流程；假设是实战中你必须核实的部分。

## 场景 B：1v2 中间玩家（你是第 2，30% 领地，25M 金币）

你是三玩家对局中的中间玩家。第一玩家 45% 领地、40M 金币。第三玩家 25% 领地、20M 金币。你 30% 领地、25M 金币。房间解局器是末日钟。你是*潜在协同 MIRV 的目标*：第一和第三玩家能联手 MIRV 你——中间玩家——因为你是最高风险形状（被两个在某种意义上都比你大的玩家夹击）。

*错误*打法是全速进攻第一玩家、指望击溃他们。这花掉你 25M 金币买一个未必杀死第一玩家的 MIRV（他们有 SAM 防线），让你剩 0M 金币、30% 领地，第三名现在有了*动机*氢弹你（你刚攻击第一玩家，你现在是恶人，第三名乐意让第一和第三联手对付你）。你输 1v2，末日波对你削弱对手。

*正确*打法是带海军护航的收入赛跑。第一步：花 1.5M 买一枚 SAM 发射器，放在为港口供血的城市集群上。第二步：花 500,000 买两个港口加一座工厂。第三步：花 250,000 买一艘战舰护航。第四步：花 50,000 买一座防御哨所。总花费 2.3M，剩 22.7M 金币与每分钟约 5M 的新收入率。战舰护航是与场景 A 的*关键*差别：1v2 中间玩家最可能被扫荡，战舰护航是最便宜的海军防御（250,000），阻止第三名捕获你的港口。

现在第一和第三玩家有三个选项。选项 1：他们联手 MIRV 你。SAM 拦截大部分 MIRV，城市集群受损但未毁，港口与工厂存活。你 28%、第一 43%、第三 25%。45% 的末日波要来，第一玩家在线以上（43% 接近 45%）而你与第三在线以下。波抽干第一玩家的领地，随后的 1v1 是你 35%+、第一 35% 或更低、第三被消灭或 10%。收入赛跑现在是你在赢的 1v1，因为你的收入率更高。选项 2：第一和第三不联手，45% 的末日波到来。波抽干第一玩家领地（他们在线以上但波仍命中），随后的 1v1 是你与第一领地大致相等、你收入率更高。选项 3：第一和第三*联手*但不 MIRV 你，而是让末日波做事。波削弱对手，随后的 1v1 同选项 2。

*假设*是这个场景中你必须核实的部分：第一和第三玩家没有*同时* MIRV（两枚同时）能压倒 SAM。如果有，SAM 防线不够，你需要*第二枚* SAM 或*重新部署*的城市集群，或你需要*强制 1v1*——与第三玩家交易土地（用一条领地带换停火，随后 1v1 是你与第一玩家，收入赛跑是你在赢的 1v1）。强制 1v1 选项是*最后手段*，只有当第三玩家是理性玩家、宁要那条领地带也不愿当协同 MIRV 目标时才可用。假设是实战中你必须核实的部分。

## 失败模式与反制

最常把核爆之后阶段搞砸的四个失败模式是：（1）过度堆 SAM 错误、（2）无视贸易强化、（3）过早全速进攻、（4）无护航的被封锁岛屿。每个都有具体反制，反制是你*在失败发生前一分钟*做的*决策*。

**失败 1：过度堆 SAM 错误。**这是晚局 Reddit 线程描述的错误："你早建了多个 6 连 SAM，仍然没能成功抵消一次氢弹。"玩家在收入回本 9M 之前花 9M（六枚 SAM、每枚 1.5M）买 SAM。反制是*排序*规则：SAM 在港口和工厂*之后*，不在之前。1.5M 的 SAM 是收入的*保护*，收入必须在保护值得 1.5M 之前先生成。具体检查：如果你花超过 50% 金币买 SAM、不到 20% 买港口和工厂，你处在过度堆 SAM 错误，修法是*停止*建 SAM、*开始*建港口-工厂走廊。

**失败 2：无视贸易强化。**这是只建陆地收入（城市）、漏掉港口-工厂走廊的错误，因为玩家不知道 v0.34.12 强化。反制是*收入率检查*：核爆之后阶段开始时，数你的陆地与贸易每分钟金币。如果贸易收入低于总收入 20%，你处在无视贸易强化错误，修法是*现在*建港口-工厂走廊、不是之后。具体检查：如果你有两座以上城市且无港口，你处在无视贸易强化错误。v0.34.12 强化是港口现在是默认终局投资的原因；无视它等于无视一个免费收入来源。

**失败 3：过早全速进攻。**这是你在 40% 领地而非 67% 时 MIRV 第二名的错误。反制是*领地检查*：如果你低于 60% 领地，全速进攻是错误打法、收入赛跑是正确打法。具体检查：如果你在 40% 领地、第二名在 30%，全速进攻让你成为协同氢弹目标，收入赛跑是唯一有效的打法。MIRV 赛跑线程的社区共识明确："除非你握有 67% 棋盘，否则不要当恶人。"67% 阈值是那条线；线下，收入赛跑是默认。

**失败 4：无护航的被封锁岛屿。**这是在无战舰护航的岛屿或海岸瓦片上建港口的错误。反制是*海军检查*：如果你的港口在敌方战舰射程内，你需要 250,000 的战舰护航*在下次贸易船抵达之前*、不是之后。具体检查：如果敌方有战舰而你没有，港口处于风险中，战舰护航是第一投资、不是第五。港口瓦片上的防御哨所（50,000）是*第二*海军投资；它添加 30 瓦防御区，让港口更难从陆地被扫荡。

四个失败的元反制是核爆之后阶段每一分钟开始时的*收入率检查*：数你的每分钟金币、数对手的、如果你的率低，*投资港口-工厂走廊*。如果你的率高，*转向领地*（相位转换）。元反制是阻止全部四个失败的单一决策，整篇指南都是关于它的。

## 模式调整：加时、末日钟、无联盟

核爆之后阶段有三个模式调整，每个都改变框架的排序。调整是：加时（收缩领地阈值）、末日钟（上升领地份额线）、无联盟（无停火、贸易路线脆弱）。本指南默认框架假设末日钟解局器；加时和无联盟调整改变默认。

**加时调整。**加时房间里，收缩领地阈值是时钟，核爆之后阶段最后 60–90 秒由领地转化主导、不是收入赛跑。排序从"港口 → 工厂 → SAM"变为"城市 → 城市 → 城市 → SAM → 港口 → 工厂"。城市第一，因为阈值在收缩、领地是货币。港口和工厂最后，因为复利论点在短加时窗口内没时间回本。具体检查：如果加时阈值在 35% 或以下，收入赛跑已结束、唯一打法是领地转化。如果加时阈值在 45% 或以上，收入赛跑仍有效、默认排序适用。加时调整是*唯一*反转复利论点的调整，[赢下加时指南](/guides/winning-overtime/)深入覆盖。

**末日钟调整。**末日钟房间里，上升领地份额线（v0.34.19 FFA 的 40% / 45% / 50% / 55% / 60%）是时钟，核爆之后阶段由 SAM 防线的*存活*与波*削弱*对手主导。默认排序适用，加一点：SAM 防线在末日钟房间里*更*重要，因为波命中线以下玩家、扛过波的玩家赢下随后的 1v1。具体检查：如果你低于下一末日波线，你是波的目标、SAM 防线是第一投资。如果你高于下一波线，波是*机会*、收入赛跑是第一投资。末日钟调整不反转复利论点；它*延长*它，因为波削弱对手、随后的 1v1 比之前的 1v2 更长。

**无联盟调整。**无联盟房间里，贸易路线脆弱，因为没有停火、敌方随时能扫荡港口。排序变为在第二港口*之前*加战舰护航和防御哨所："港口 → 工厂 → SAM → 战舰护航 → 防御哨所 → 港口（二）→ 工厂（二）"。战舰护航（250,000）和防御哨所（50,000）是贸易路线的*保护*，无联盟房间里保护比有联盟房间更值钱，因为敌方不受停火约束就能扫荡。具体检查：如果房间是无联盟且你有海岸瓦片上的港口，战舰护航是第一投资、不是第五。无联盟调整[无联盟模式指南](/guides/no-alliances-mode/)深入覆盖。

三个调整有一条共同线索：*保护*（SAM、战舰护航、防御哨所）在*威胁*更高的模式（末日钟波、无联盟扫荡）里更值钱、在*时钟*是领地阈值的模式（加时）里更不值钱。元规则与框架一节相同：保护在收入*之后*，但保护的*量*由模式决定。加时房间需要最少保护（时钟是领地阈值、不是敌方）。末日钟房间需要最多 SAM 保护（波是威胁）。无联盟房间需要最多海军保护（扫荡是威胁）。

## 地图调整：岛、大陆、小图

核爆之后阶段有三个地图调整，每个都改变港口-工厂走廊的*形状*。调整是：岛地图（加那利群岛、马达加斯加、克里特、济州、斯瓦尔巴、塞布尔岛）、大陆地图（世界、非洲、中东）、小地图（4 玩家）。本指南默认框架假设大陆地图；岛和小图调整改变默认。

**岛调整。**岛地图上，港口天然被水防御：对手要捕获必须穿越开阔水域、需要他们自己的战舰护航。港口-工厂走廊是*岛屿建造的核心*，"岛上人"奇策是岛屿建造的逻辑极端。岛地图排序是："港口 → 工厂 → 港口（二）→ 战舰护航 → SAM → 防御哨所 → 工厂（二）→ 城市"。两个港口在 SAM 之前，因为岛上港口天然防御、收入赛跑是生存策略。战舰护航在 SAM 之前，因为海军威胁是岛地图上第一个威胁。具体检查：如果你在岛地图上、敌方有战舰，战舰护航是第一投资、不是第五。岛调整[岛屿防御指南](/guides/island-defense/)深入覆盖。

**大陆调整。**大陆地图上，港口天然防御较弱，*铁路走廊*是关键：连接的港口-工厂铁路线比孤立港口更难被扫荡。大陆地图排序是默认："港口 → 工厂 → SAM → 城市 → 战舰护航 → 防御哨所 → 港口（二）→ 工厂（二）"。SAM 在战舰护航之前，因为陆地威胁是大陆地图上第一个威胁。具体检查：如果你在大陆地图上、敌方在你港口陆地射程内，SAM 是第一投资、不是第三。大陆调整是默认，铁路走廊细节见[火车网络指南](/guides/train-network/)。

**小图调整。**小地图（4 玩家）上，末日波来得更快、1v2 是默认形状。小图排序是 1v2 中间玩家排序："港口 → 工厂 → 港口（二）→ SAM → 战舰护航 → 防御哨所 → 工厂（二）→ 城市"。两个港口在 SAM 之前，因为 1v2 是默认形状、收入赛跑是生存策略。具体检查：如果你在小图上、你是中间玩家，1v2 中间玩家排序适用、不是默认。小图调整是*唯一*改变 1v2 *形状*的调整，MIRV 赛跑线程的社区共识（"小图上 5 枚氢弹 ≈ 一枚 MIRV"）反映这一点。

三个地图调整有一条共同线索：港口的*天然防御*（岛上的水、大陆的铁路）决定*保护投资的顺序*。元规则与模式调整一节相同：保护在收入*之后*，但保护的*类型*（海军、陆地、或两者）由地图决定。岛地图海军保护第一。大陆地图陆地保护第一。小图两者都要、按 1v2 中间玩家顺序。

## 成本表与实操清单

下表是核爆之后阶段的参考。数字来自生成数据（截至 v0.34.x 线当前）与 v0.34.19 末日波数值。

| 资产 | 成本 | 核爆之后阶段角色 |
|---|---|---|
| 港口 | 125,000 | 复利收入（贸易船） |
| 城市 | 125,000 | 陆地收入 + 领地 |
| 工厂 | 125,000 | 港口/城市收入乘数 |
| 防御哨所 | 50,000 | 30 瓦防御区（最便宜保护） |
| 战舰 | 250,000 | 海军护航（港口保护） |
| 导弹井 | 1,000,000 | 核弹进攻（仅全速进攻） |
| SAM 发射器 | 1,500,000 | 核弹防御（氢弹存活） |

核爆之后阶段的实操清单是六步决策流程。**第一步：读房间解局器。**加时还是末日钟？这决定排序。**第二步：读形状。**你是第 1、第 2、还是 1v2 中间玩家？这决定排序。**第三步：读地图。**你在岛、大陆、还是小图？这决定保护类型。**第四步：读收入率。**你的每分钟金币高于还是低于对手？高则转领地；低则建港口-工厂走廊。**第五步：读 SAM 防线。**你有一枚 6 级以上 SAM 保护为港口供血的城市集群吗？没有则 SAM 是下一个投资。**第六步：读海军护航。**你有一艘战舰护航保护港口吗？没有则战舰护航是下一个投资。

清单是框架的*操作*版本：框架是*为什么*，清单是*什么时候*。框架告诉你排序；清单告诉你排序中*下一个*投资。六步是你在核爆之后阶段每一分钟开始做的决策，决策就是*核爆之后持续力*：v0.34.12 强化让它成为默认、加时与末日钟解局器奖励的缓慢、复利、收入优先终局。六步中有两步是*快*检查（三秒内可跑完）：第一步（读解局器）和第四步（读收入率）；它们决定下一分钟的*形状*。两步是*慢*检查（需要数对手资产）：第五步（读 SAM 防线）和第六步（读海军护航）；它们决定下一分钟的*保护*。慢检查的元规则是：如果你不确定答案，*按最差假设*建保护。误报（不需要却建 SAM）的成本是 1.5M 加一分钟收入损失；误漏（需要却不建 SAM）的成本是城市集群和港口-工厂走廊。不对称是慢检查默认建保护的原因。

如果你能在十秒内跑完六步（你应该能，因为数字在上方表里、解局器在房间 UI 可见），你就在正确运行核爆之后阶段，比赛其余是把收入转化为解局器奖励的领地。十秒检查是*控制*核爆之后阶段的玩家与*被它控制*的玩家的差别：控制者每分钟跑六步、被控制者只在核爆之后阶段开始时跑一次然后被动反应。被动反应是失败模式；六步是反制。
