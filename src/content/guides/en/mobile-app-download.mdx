## Direct answer

**OpenFront's current official mobile route is the game at [openfront.io](https://openfront.io/) in a modern browser; the official v0.34.0-beta1 release provides no APK download.**

That sentence has a narrow date and source boundary. The tagged [OpenFrontIO README](https://github.com/openfrontio/OpenFrontIO/blob/v0.34.0-beta1/README.md) calls OpenFront an online game and lists modern web browsers as the cross-platform client. The official [v0.34.0-beta1 Release](https://github.com/openfrontio/OpenFrontIO/releases/tag/v0.34.0-beta1), published on September 10, 2026, has no attached downloadable assets. It does not offer an Android package, an iPhone App Store package, or a separate mobile installer.

Open the official site directly instead of searching for an APK mirror. A third-party file can reuse the OpenFront name without being an official build, and this page cannot verify its code, signature, update channel, or account handling. The absence of a release asset is not a promise that OpenFront will never ship a native app; it is the verified state of the current release on the date above.

## What “Add to Home Screen” does

On iOS, OpenFront's tagged interface tells players whose browser cannot enter fullscreen to use **Add to Home Screen**. The official [English interface strings](https://github.com/openfrontio/OpenFrontIO/blob/v0.34.0-beta1/resources/lang/en.json#L882-L891) say that opening from the Home Screen launches fullscreen without the address bar.

This creates a launcher icon for the website. It is not evidence of an App Store build, and it does not replace the web client with a different rules engine. Start in Safari, open the browser's Share menu, choose Add to Home Screen, and launch the new icon. Android browsers may also offer an install or home-screen shortcut, but the exact label depends on the browser; use the official domain as the destination.

Once the game opens, continue with the [mobile controls guide](/guides/mobile-controls/) for taps, pans, pinch zoom, radial actions, and Warship selection. Use the [first-match guide](/guides/first-match/) for spawn and opening decisions. This page owns only the app, download, and APK question.
