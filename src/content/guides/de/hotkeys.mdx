> Alles Folgende ist die **Standard**-Belegung. Seit v24 lässt sich jede Taste unter **Settings → Keybindings** neu zuweisen, einige können ganz aufgehoben werden. Auf macOS `Ctrl` als `Cmd` lesen.

## „Wie feuert mein Gegner so schnell Atombomben?“

Fast jeder neue Spieler stellt diese Frage irgendwann. Es ist **kein externes Tool und kein Autoclicker nötig** — es sind zwei eingebaute Mechaniken.

1. **Bau-Zifferntasten bewaffnen sofort eine Struktur.** Drücke `8`, und dein Cursor hält bereits eine Atombombe — kein Radial-Menü, kein Durchklicken. Linksklick auf ein Ziel startet den Abschuss.
2. **Bomben bleiben nach dem Abschuss bewaffnet.** Wenn du eine Atombombe (`8`) oder Wasserstoffbombe (`9`) platzierst, bleibt der Bau-„Geist“ am Cursor — du klickst also einfach weiter mit links und lässt Bombe um Bombe auf verschiedene Ziele fallen. `Esc` oder Rechtsklick beendet es.

Das „Shift halten und klicken zum Wiederholen“ aus anderen Spielen ist hier also nicht die genaue Belegung — aber bei Bomben ist das Äquivalent noch einfacher: **einmal `8` tippen, dann klick, klick, klick.** Jedes andere Gebäude löscht den Geist nach einer Platzierung, du tippst die Ziffer also jedes Mal neu.

## Bau- / Einheitentasten

Ziffer drücken, dann mit links die Stelle anklicken. Umgeht das Radial-Menü komplett — so reihen schnelle Spieler im Endgame Gebäude (und Bomben) aneinander.

| Taste | Baut |
| --- | --- |
| `1` | Stadt |
| `2` | Fabrik |
| `3` | Hafen |
| `4` | Verteidigungsposten |
| `5` | Raketensilo |
| `6` | SAM-Werfer |
| `7` | Kriegsschiff |
| `8` | Atombombe — **bleibt für Dauerfeuer bewaffnet** |
| `9` | Wasserstoffbombe — **bleibt für Dauerfeuer bewaffnet** |
| `0` | MIRV |

- `Enter` — die bewaffnete Einheit unter dem Cursor bauen (statt zu klicken).
- `Esc` — die Bauvorschau abbrechen.
- `U` — die Abschuss-Bogenrichtung (oben / unten) einer bewaffneten Atom- oder Wasserstoffbombe umkehren.

## Maus

Standardschema. Die Tasten lassen sich unter **Settings → „Left click opens menu“** vertauschen.

| Aktion | Ergebnis |
| --- | --- |
| Linksklick auf feindliche / herrenlose Grenze | Angreifen, oder über Wasser automatisch einen Transporter senden |
| Linksklick auf eigenes Land mit bewaffnetem Bau | Dieses Gebäude platzieren |
| Rechtsklick | Radial- / Build-Menü öffnen |
| `Ctrl` + Linksklick | Build-Menü an dieser Stelle öffnen |
| `Alt` + Linksklick | Emote-Menü öffnen |
| `Shift` + Ziehen | Mehrere Kriegsschiffe per Box auswählen |
| Attack-Ratio-Regler ziehen | Anteil der pro Angriff entsandten Truppen einstellen |
| Mausrad | Zoom |
| Mittelklick ziehen | Ansicht verschieben |

## Radial-Menü (in v24 überarbeitet)

Rechtsklick auf eigenes Land öffnet es. Jetzt mehrstufig: die Kerngebäude auf dem Ring, mit SAM, Fabrik, Schiff und Upgrade-Optionen auf der zweiten Ebene.

```
       Build City
            |
    Port -- ⊕ -- Defense
            |
       Missile Silo
```

Das Radial-Menü ist praktisch, solange du die Symbole lernst — aber sobald du weißt, was du willst, sind **die obigen Zifferntasten deutlich schneller**.

## Aktions-Kombos

- **Bomben-Salve**: `8` → jedes Ziel nacheinander anklicken (die Atombombe bleibt bewaffnet). Für Wasserstoffbomben auf `9` wechseln.
- **Küstenverteidigung**: `3` (Hafen) → platzieren, dann `4` (Verteidigungsposten) → dicht an die Innenseite des Hafens setzen.
- **Schnelle Wirtschaft**: `1` (Stadt) → freies Gelände anklicken; der Geist verschwindet, also `1` für die nächste neu tippen.
- **Bündnis**: über den Rivalen fahren und `K` drücken, oder seinen Avatar anklicken → Request Alliance.

## Kampfrhythmus

Die Mausarbeit guter Spieler kreist zwischen drei Bereichen:

1. **Die Mitte des eigenen Landes** — bauen und aufwerten (jetzt meist per Zifferntasten).
2. **Die Grenze** — Angriffe und Transporte.
3. **Die Minimap / Spielerliste** — die Expansionskurven der Rivalen beobachten.

Egal welcher Spielstil — die Grundregel lautet: <strong>verlasse nicht die Schlachtfeldansicht</strong> — OpenFront ist schnell, und 10 Sekunden Abwesenheit können reichen, damit eine Stadt den Besitzer wechselt.
