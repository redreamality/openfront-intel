## Direkte Antwort: die schnellsten OpenFront-Steuerungen

Drücke eine Zahl, um Gebäude oder Einheit scharfzuschalten, und linksklicke dann auf das Ziel. Die Ziffernreihe überspringt das Radialmenü und macht Bauen oder Starten deutlich schneller.

Für wiederholte Nuklearstarts drückst du einmal `8` für eine Atombombe oder `9` für eine Wasserstoffbombe. Die Nuke bleibt nach dem Start aktiv, sodass du weitere Ziele linksklicken kannst.

Kein Autoclicker oder externes Tool ist nötig. Drücke `Esc` oder rechtsklicke zum Abbrechen. Andere Gebäude verschwinden meist nach einer Platzierung und müssen vor dem nächsten Bau erneut gewählt werden.

Das sind die mit der v33-Referenz dieser Website abgeglichenen Standardsteuerungen. Seit v24 lassen sich Tasten unter **Settings → Keybindings** neu belegen oder vollständig lösen.

Auf macOS liest du `Ctrl` als `Cmd`. Reagiert eine Taste nicht, prüfe zuerst die Tastenbelegung im Spiel, bevor du annimmst, die Aktion sei entfernt worden.

## Konzepte vor dem Auswendiglernen

OpenFront-Eingaben sind kontextabhängig. Ein Linksklick kann eine Grenze angreifen, einen Transport über Wasser senden oder ein aktives Gebäude platzieren. Entscheidend sind Zeigerposition und vorherige Auswahl.

Ein **aktiver Bau** ist die Vorschau am Cursor nach Auswahl einer Struktur oder Waffe. Zifferntasten erzeugen diesen Zustand sofort. `Esc` bricht ab, `Enter` bestätigt am Cursor.

Das **Radialmenü** ist das visuelle Rechtsklick-Baumenü. Es hilft beim Lernen der Symbole und bei Upgrades. Zifferntasten sind schneller, sobald du die gewünschte Option kennst.

Die **Attack Ratio** ist der Truppenanteil eines Angriffs. `T` senkt ihn, `Y` erhöht ihn. Beide Tasten verändern dieselbe Entscheidung wie der Regler auf dem Bildschirm.

Kameratasten geben kein Gold aus und starten keinen Angriff. Nutze sie, um den Cursor an der aktiven Front zu halten und trotzdem Kern, Küste und Handelswege zu prüfen.

## Zifferntasten für Gebäude und Einheiten

Drücke die Zahl, bewege den Cursor an einen gültigen Ort oder auf ein Ziel und linksklicke. Diese Gruppe ist besonders wertvoll, weil sie wiederholte Menünavigation entfernt.

| Taste | Aktiviert |
| --- | --- |
| `1` | City |
| `2` | Factory |
| `3` | Port |
| `4` | Defense Post |
| `5` | Missile Silo |
| `6` | SAM Launcher |
| `7` | Warship |
| `8` | Atombombe — bleibt nach dem Start aktiv |
| `9` | Wasserstoffbombe — bleibt nach dem Start aktiv |
| `0` | MIRV |

`Enter` bestätigt das aktive Element am Cursor. `Esc` bricht die Vorschau ab. Bei aktiver Atom- oder Wasserstoffbombe dreht `U` den Startbogen zwischen den zwei Richtungen um.

Die Tasten umgehen keine Spielregeln. Du brauchst weiterhin genug Gold, nötige Infrastruktur, ein gültiges Ziel oder Feld und eine Lobbyoption, die das Element erlaubt.

## Maussteuerung

Die Tabelle nutzt das Standardschema. Unter **Settings → Left click opens menu** kannst du das Menüverhalten umkehren. Prüfe diese Option, wenn sich Klicks entgegengesetzt anfühlen.

| Eingabe | Standardergebnis |
| --- | --- |
| Linksklick auf feindliche oder herrenlose Grenze | Angreifen oder Transport über Wasser senden |
| Linksklick auf eigenes Land bei aktivem Bau | Aktives Gebäude platzieren |
| Rechtsklick | In v33.1 eine aktive Warship-/Bootsauswahl aufheben; sonst Radial- oder Baumenü öffnen |
| `Ctrl` + Linksklick | Baumenü an dieser Stelle öffnen |
| `Alt` + Linksklick | Emote-Menü öffnen |
| `Shift` + Ziehen | Mehrere Warships per Box auswählen |
| Mausrad | Zoomen |
| Mittlere Maustaste ziehen | Ansicht verschieben |

Verwechsle `Shift` + Ziehen nicht mit Wiederholungsbau. Die dokumentierte Wiederholung gilt für aktive Nukes. Citys, Ports, Factories und Verteidigungsbauten musst du erneut scharfschalten.

## Ansichts- und Kameratasten

| Taste | Aktion |
| --- | --- |
| `Space` | Zwischen Gelände- und Länderansicht wechseln |
| `M` | Koordinatenraster ein- oder ausblenden |
| `C` | Kamera auf die eigene Nation zentrieren |
| `Q` / `E` | Heraus- / hineinzoomen |
| `+` / `-` | Alternative Zoomsteuerung |
| `W` `A` `S` `D` | Kamera verschieben |
| `P` | Pausieren oder fortsetzen |
| `,` / `.` | Spieltempo im Einzelspieler senken oder erhöhen |

Nutze `C` als Rückholtaste. Wenn langes Verschieben oder Zoomen deine Orientierung zerstört, bringt ein Druck die Aufmerksamkeit zur eigenen Nation zurück.

`Space` ist ein Lesewerkzeug, kein bloßer Effekt. Die Ansichten können Gelände oder politische Besitzverhältnisse vor einem Truppeneinsatz klarer zeigen.

## Kampf-, Diplomatie- und Hilfstasten

| Taste | Aktion |
| --- | --- |
| `T` / `Y` | Attack Ratio senken / erhöhen |
| `B` | Bootsangriff zum Ziel starten |
| `G` | Bodenangriff zum Ziel starten |
| `Shift` + `R` | Gegen den letzten Angreifer zurückschlagen |
| `F` | Alle eigenen Warships auswählen |
| `Shift` + Ziehen | Mehrere Warships auswählen |
| `U` | Bogen einer aktiven Atom- oder Wasserstoffbombe drehen |
| `K` | Allianz mit dem Spieler unter dem Cursor anfragen |
| `L` | Allianz brechen |
| `Alt` + `R` | Grafik zurücksetzen |
| `Esc` | Menü schließen oder Bauvorschau abbrechen |

`K` und `L` wurden in den v31-Release-Notes als schnellere Allianzsteuerung hervorgehoben. Sie helfen, wenn eine diplomatische Entscheidung ohne weiteres Menü über dem Schlachtfeld fallen muss.

Nutze `Shift` + `R` vorsichtig. Es zielt auf den letzten Angreifer und ist schneller, aber weniger überlegt als eine Grenzwahl nach Prüfung der strategischen Gesamtlage.

## Zwischen Hotkey und Radialmenü entscheiden

Nutze eine Zifferntaste, wenn die Entscheidung bereits steht. Weißt du, dass du einen Defense Post brauchst, spart `4` Zeit und lässt mehr Aufmerksamkeit für Truppen, Grenzen und Geschosse.

Nutze das Radialmenü, wenn du noch entscheidest. Es zeigt verfügbare Bauten und Unterebenen und ist bei unbekannten Upgrades oder einer frisch geänderten Belegung sicherer.

Nutze die kompakte [Shortcut-Referenz](/de/shortcuts/) für schnelles Nachschlagen. Dieser Guide erklärt Gründe, Übungen und Fehlerbehebung hinter den Steuerungen.

| Situation | Bester Steuerweg | Grund |
| --- | --- | --- |
| Eine vertraute Struktur | Zifferntaste, dann Klick | Wenigste Aktionen |
| Mehrere Atom- oder Wasserstoffziele | `8` oder `9`, dann wiederholte Klicks | Nuke bleibt aktiv |
| Unbekanntes Upgrade | Radialmenü | Visuelle Bestätigung |
| Kamera verloren | `C` | Rückkehr zur eigenen Nation |
| Feine Änderung der Attack Ratio | Regler | Mehr visuelle Präzision |
| Schnelle Änderung der Attack Ratio | `T` oder `Y` | Cursor bleibt an der Front |
| Mehrere Warships | `F` oder `Shift` + Ziehen | Gruppensteuerung |

## Eine zehnminütige Übungsroutine

Übe im Einzelspieler, damit `P`, `,` und `.` verfügbar sind. Das Ziel ist kein Sieg, sondern die Pause zwischen erkanntem Bedarf und passendem Befehl zu entfernen.

### Schritt 1: Standardbelegung prüfen

Öffne vor dem Match **Settings → Keybindings**. Vergleiche Ziffernreihe, Kamera und Attack Ratio mit dieser Seite. Setze Abweichungen zurück oder notiere sie.

Prüfe auch die Mausoption. Eine umgekehrte Menütaste verändert jede Bauübung, selbst wenn alle Tastaturbelegungen stimmen.

### Schritt 2: Kamerarückkehr lernen

Bewege dich mit `W`, `A`, `S` und `D` weg, zoome mit `Q` und `E` und drücke dann `C`. Wiederhole, bis die Zentrierung automatisch wird.

Schalte `Space` beim Blick auf eine Grenze um. So lernst du, die Informationsebene zu wechseln, ohne den Cursor vom umkämpften Bereich zu entfernen.

### Schritt 3: Ohne Radialmenü bauen

Aktiviere mit `1` eine City, platziere sie und drücke `Esc`. Wiederhole mit `2` bis `6` nur, wenn das Element verfügbar und bezahlbar ist.

Beobachte nach jeder Platzierung, ob eine Vorschau bleibt. Normale Strukturen verschwinden nach einem Bau. Dieser Unterschied verhindert versehentliche Doppelkäufe.

### Schritt 4: Grenzsteuerung üben

Halte den Cursor über eine sichere Grenze. Drücke `T` und `Y`, beobachte die Attack Ratio und starte dann einen bewussten Bodenangriff mit `G` oder dem normalen Grenzklick.

Hämmere nicht auf die Verhältnis-Tasten. Verbinde jede Richtung mit ihrer Wirkung und kehre vor dem nächsten Angriff zu einem bekannten Wert zurück.

### Schritt 5: Marineauswahl üben

Sind Warships verfügbar, wähle mit `F` alle aus. Lösche die Auswahl und markiere mit `Shift` + Ziehen nur eine lokale Gruppe.

Beide Befehle lösen andere Probleme. `F` ist die globale Antwort, die Boxauswahl lässt Schiffe an einem anderen Port oder Küstenabschnitt zurück.

### Schritt 6: Nuklearstart sicher üben

Baue in einer Lobby mit aktiven Nukes die nötige Infrastruktur und spare genug Gold. Drücke `8`, wähle ein gültiges Ziel, klicke einmal und prüfe, ob die Atombombe aktiv bleibt.

Wechsle ohne erneutes `8` zu einem zweiten Ziel. Drücke dann `Esc` und bestätige, dass ein weiterer Klick keine aktive Bombe mehr startet.

Wiederhole vor dem Start mit `U`, um den Bogenwechsel zu erkennen. Es ist eine Steuerübung, kein Beweis, dass eine Bogenrichtung immer strategisch besser ist.

## Praktische Aktionsfolgen

Die folgenden Folgen sind Gedächtnismuster, keine allgemeine Bauorder. Prüfe Gold, Gelände, Lobby-Modifikatoren und Gefahren vor jeder Ausgabe.

### Schnelle Grenzverstärkung

1. Drücke `C`, wenn die Kamera verschoben ist.
2. Bewege dich zur bedrohten Grenze.
3. Drücke `4`, um einen Defense Post zu aktivieren.
4. Platziere ihn so, dass seine 30-Tile-Zone den relevanten Weg deckt.
5. Drücke `Esc`, falls eine Vorschau bleibt.

Ein Defense Post beginnt bei 50.000 Gold und gibt innerhalb seiner Reichweite `mag ×5` und `speed ×3`. Der Hotkey spart Menüzeit, doch die Platzierung entscheidet über den Kampfbonus.

### Wirtschaft prüfen, ohne die Front zu verlieren

1. Halte den Cursor nahe der Grenze.
2. Drücke `C`, um den Kern zu prüfen.
3. Nutze `1`, `2` oder `3` für geplante City, Factory oder Port.
4. Kehre mit Kameratasten zur Front zurück.
5. Ändere mit `T` oder `Y` nur bei veränderter Lage die Attack Ratio.

Dieser Rhythmus trennt Wirtschaftsentscheidung und mechanische Ausführung. Entscheide zuerst den Bau und nutze dann die Taste, um weniger Aufmerksamkeit für die Platzierung zu verbrauchen.

### Nuklearsalve und sauberes Abbrechen

1. Bestätige, dass die Lobby Nukes erlaubt.
2. Bestätige Waffe, Gold und Ziel.
3. Drücke `8` für Atom oder `9` für Wasserstoff.
4. Klicke jedes geplante Ziel einmal an.
5. Drücke direkt nach dem letzten Start `Esc`.

Das Abbrechen ist wichtig. Eine aktive Waffe kann einen späteren Klick in einen teuren Fehler verwandeln, während du verschiebst, prüfst oder zur Bodensteuerung wechselst.

### Reaktion an der Küste

1. Drücke `F`, wenn alle Warships reagieren müssen.
2. Nutze `Shift` + Ziehen, wenn nur eine Flotte ziehen soll.
3. Verschiebe mit mittlerer Maustaste oder Kameratasten.
4. Lass die übrige Flotte an der Küste, die sie weiter schützt.

Die v31-Notizen ergänzten Mehrfachauswahl und Rückzug für Warships. Schnelle Auswahl hilft nur, wenn du nicht jede andere Seeroute ungeschützt lässt.

## Zahlenbeispiele: Tempo ist nicht gleich Wert

Der Hotkey ist kostenlos, die Aktion nicht. Eine City kostet zunächst 125.000 Gold und gibt pro Stufe 250.000 Truppenlimit. Schnelles `1` macht eine unnötige City nicht gut.

Eine Atombombe kostet 750.000 Gold, eine Wasserstoffbombe 5.000.000. Eine MIRV beginnt bei 25.000.000 und addiert 15.000.000 für jeden bereits erfolgten Start.

Ein versehentlicher Start mit `9` kostet damit so viel wie sechs Atombomben plus 500.000 Gold. Beende jede Wiederholungsfolge mit `Esc`.

Ein Missile Silo kostet 1.000.000 Gold, der erste SAM Launcher 1.500.000. `5` und `6` beschleunigen die Platzierung, entfernen aber nicht die Infrastrukturentscheidung über 2.500.000.

Der erste Defense Post kostet 50.000 Gold. Sein Preis wächst mit der vorhandenen Zahl bis 250.000. `4` ist am wertvollsten, wenn du den richtigen Engpass bereits erkannt hast.

## Häufige Fehlermuster

### „Ich drücke die Zahl und nichts passiert“

Prüfe zuerst **Settings → Keybindings**. Die Taste kann geändert oder gelöst sein. Prüfe danach Gold, nötige Infrastruktur, Lobby-Modifikatoren und einen gültigen Ort unter dem Cursor.

Drücke nicht weiter, ohne den Zustand zu verstehen. Wiederholte Eingaben können zum überraschenden Kauf oder Start werden, sobald die fehlende Bedingung erfüllt ist.

### „Der nächste Klick startete noch eine Nuke“

Atom- und Wasserstoffbomben bleiben nach dem Abschuss aktiv. Das ist die beabsichtigte Wiederholungsfunktion. Drücke nach der geplanten Salve `Esc` oder rechtsklicke.

Baue das Abbrechen ins Muskelgedächtnis ein: Waffentaste, Ziele, `Esc`. Der letzte Befehl gehört zur Startfolge und ist keine optionale Aufräumarbeit.

### „Shift-Klick wiederholte mein Gebäude nicht“

Die Standardreferenz beschreibt `Shift` nicht als allgemeinen Wiederholungsmodifikator. `Shift` + Ziehen wählt Warships. Aktiviere normale Strukturen vor jeder Platzierung neu.

### „Mein Klick griff an, statt ein Menü zu öffnen“

Prüfe **Left click opens menu** und das Tile unter dem Cursor. Die Standardaktion hängt von Besitz, Wasserzugang und aktivem Bau ab.

Drücke vor der Fehlersuche `Esc`. Das Löschen des aktiven Zustands entfernt eine Ursache für Mehrdeutigkeit beim nächsten Klick.

### „Alle auswählen bewegte Schiffe, die zu Hause bleiben sollten“

`F` wählt die gesamte Warship-Flotte. Nutze `Shift` + Ziehen für eine regionale Gruppe. Globale Auswahl ist schnell, kann aber anderswo eine Küste öffnen.

### „Vergeltung traf das falsche strategische Problem“

`Shift` + `R` antwortet auf den letzten Angreifer, nicht zwingend den gefährlichsten Gegner. Nutze es nur, wenn die sofortige Vergeltung zum Gesamtplan passt.

### „Ich gewann das Eingaberennen und verlor die Wirtschaft“

Hotkeys verkürzen Ausführung, verbessern aber keine Entscheidung. Ein schneller Bau mit geringem Wert verbraucht weiterhin Gold und Aufmerksamkeit für Verteidigung, Handel oder Cap.

Nutze den [Guide zu Wirtschaftsgrundlagen](/de/strategies/economy-fundamentals/) für die Kaufentscheidung. Kehre hierher zurück, um sie schneller auszuführen.

## Anpassung gegen schnelle Gegner

Feuert ein Gegner mehrere Nukes schnell, denke zuerst an aktive Wiederholungs-Zifferntasten statt an Automatisierung.

Atom- und Wasserstoffbomben sind abfangbar. Der MIRV-Träger ist kein Ziel, getrennte Sprengköpfe folgen jedoch der normalen Flugbahnprüfung.

Nutze überlappende SAM-Abdeckung für wertvolle Kerne, aber bündele nicht jeden Werfer in einem Sprengbereich. Der [Guide zur nuklearen Abschreckung](/de/strategies/nuclear-deterrence/) erklärt den Tausch.

Baut ein Gegner schnell an einer Grenze, verlangsame deine Eingabe für eine Sekunde. Prüfe Gelände, Defense-Post-Abdeckung und Attack Ratio, bevor du sein Tempo kopierst.

Verursacht deine eigene Belegung Konflikte, halte häufige Aktionen nah beieinander. Bewahre klare Tasten für Abbruch, Kamerarückkehr, Attack Ratio und oft genutzte Bauten.

Sind Nukes deaktiviert, verschwinden die Entscheidungen für `8`, `9` und `0`. Nutze die Aufmerksamkeit für Kamera, Defense Posts, Citys, Ports, Factories und Warships.

## FAQ

### Wie feuern Spieler Nukes so schnell?

Sie drücken einmal `8` oder `9` und klicken mehrere Ziele. Atom- und Wasserstoffbomben bleiben nach jedem Start aktiv. Kein externes Wiederholungswerkzeug ist nötig.

### Wie stoppe ich das Wiederholungsfeuer?

Drücke `Esc` oder rechtsklicke nach dem letzten geplanten Ziel. Prüfe vor normalen Klicks, ob die aktive Vorschau verschwunden ist.

### Wiederholt `Shift` jedes Gebäude?

Nein. Die dokumentierte Mausaktion mit `Shift` ist die Boxauswahl mehrerer Warships. Aktiviere normale Gebäude nach jeder Platzierung erneut mit ihrer Zifferntaste.

### Kann ich alle Tasten neu belegen?

Die v33-Referenz bestätigt, dass jede Taste unter **Settings → Keybindings** geändert oder gelöst werden kann. Deine lokalen Einstellungen haben Vorrang vor dieser Standardliste.

### Was macht `U`?

Es dreht den Startbogen einer aktiven Atom- oder Wasserstoffbombe. Es verändert weder den dokumentierten Radius noch die Abfangbarkeit durch SAM.

### Wie zentriere ich die Karte am schnellsten?

Drücke `C`, um die Kamera auf deine Nation zu setzen. Nutze es nach langer Bewegung, einer fernen Marineprüfung oder einem Scan nach Nuklearzielen.

### Soll ich für Warships `F` oder Boxauswahl nutzen?

Nutze `F`, wenn die ganze Flotte reagieren soll. Nutze `Shift` + Ziehen, wenn eine andere Küste, ein Port oder Wasserweg lokale Schiffe behalten muss.

### Gibt es Pause und Tempo im Multiplayer?

Die Standardreferenz listet `,` und `.` als Einzelspieler-Tempotasten. Plane im Multiplayer keine Reaktion um Pause oder veränderte Geschwindigkeit.

### Warum verhält sich Linksklick auf verschiedenen Tiles anders?

Die Eingabe ist kontextabhängig. Je nach Cursorort und aktivem Zustand kann sie angreifen, einen Transport starten oder einen Bau platzieren.
